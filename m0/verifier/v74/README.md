## Scope limits

V74 defines acceptance of the configured construction path; definition or local tooling success alone is not a passing acceptance run. Whole-branch independent review, a clean same-SHA run and hosted artifacts are reported separately. Concurrent dispatch, complete A7, Mac acceptance, B1–B5, supplier independence, invoice verification, arbitrary custom-constructor correctness, machine power-loss durability and framework release completion remain open. No live campaign migration or superiority claim follows from loopback fixtures.
