# v76 Linux acceptance

V76 retains all v75 checks and commands and verifies the v75 source and wrappers. The active full-regression limit is 2100 seconds, the outer runner limit is 3300 seconds, and the CI job limit remains 60 minutes. The measured adjustment from the original 1500/3000-second limits is recorded in the [v76 plan](../../../docs/superpowers/plans/2026-11-06-acceptance-v76.md). Historical failed or timed-out runs remain unchanged.
