## 二、压力测试结论：4 个维度级缺口

### 缺口 G1（最重要）：Candidate 层级化 —— "被进化对象上移"是 2026 年共同趋势
dgm、AIDE²、SEAL、MetaSkill-Evolve、EvolveNet、prime-agent **六个系统**都把 Candidate 从"任务解工件"上移为某种"做研究的程序"：agent 自身代码库（dgm/AIDE²）、解+自写验证器的联合状态 (π,T)（SEAL）、(skill, meta-skill) 二元组（MetaSkill-Evolve）、harness（EvolveNet）、harness 操作手册（prime-agent）。
**修订**：`Candidate` 增加 `level` 字段：`L0=任务解工件 / L1=求解程序(ExecutorSpec/harness/skill) / L2=改进策略(meta-skill/验证器)`。Evaluator 对 L1+ 的语义变为"跑若干任务后聚合"（嵌套/元评估）。

### 缺口 G2：信息边界 / 可见性 —— "哪个模块能看见什么"是一等设计变量
SEAL 的密封审计（对 agent 只泄露 1 bit）、EvolveNet 的数据本地性（L1 不出域，只有 L2/L3 跨界）、ShinkaEvolve 的 public/private 指标划分、AIDE² 的 public/private 双分数、BigBang-v1 的答案隔离——五个独立工作从不同方向撞上同一维度。
**修订**：新增横切轴 **X3 Visibility/Trust Boundary**：`EvalResult` 指标带可见性标注（public/private），ExecutorSpec 的 `context_projection` 之外增加 `forbidden_channels`；评估卫生（decontamination、答案隔离）从 X1 拆出归入 X3。

### 缺口 G3：模块可进化性标注 —— "固定 vs 可配置 vs 可学习 vs 可自我改写"
MetaSkill-Evolve（M2/M3 可进化）、OpenRSI（算子策略被 RL 训练）、ShinkaEvolve（meta prompt 进化）、dgm（刻意冻结 exploration 循环）、AIDE²（自我改进把反作弊机制改坏而不自知）。
**修订**：每个模块实例增加 `evolvability: fixed | configurable | learnable | self_modifiable` 元属性；**X1 谱系必须覆盖 M8/M9 自身代码的版本**（AIDE² 的活例：谱系审计才发现统计反作弊层已失效）。dgm 的"冻结边界声明"是正面先例。

### 缺口 G4：评估的"可靠性"轴与"归因"轴 —— 与带宽正交
Simple Baselines 证明 ~100 题小验证集让复杂 scaffold 的选择主要是噪声（重评后 P(Shinka>IID RS)=0.49）；PAST-Bench 把 Task score 与 Mechanism score 解耦（分数涨了≠通路对）。
**修订**：M8 从单一"带宽"轴扩为三根正交轴：**带宽 × 统计可靠性（评估次数/级联/CI/PoI） × 归因正确性（通路证据）**。M8/M9 增加"内生 vs 外生"标注（验收信号是否 agent 可影响——SEAL 的信息论下界）。

## 三、抽象得到强验证的方面（不是缺口，是确认）

1. **M2 四算子集独立印证**：OpenRSI 的 Draft/Improve/Debug/Crossover 与我们抽象的四算子**完全同构**；AIDE 内环同为 draft/debug/improve。可作为 M2 最小完备算子集基准。
2. **M5 三层记忆被自发复现**：prime-agent（轨迹/lessons/executable skills）、MetaSkill-Evolve（历史/inspiration/meta-skill）、OpenRSI（program DB/经验先验）都独立形成 L1→L3；且 **L2 洞见层普遍最弱**——正是我们框架的差异化空间（与此前 AIRA/Arbor 结论一致）。
3. **M9 设计趋同**：保守差分证据 + 回滚 + 最小泄露（SEAL 1 bit、EvolveNet per-item 翻转 gate、MetaSkill ΔU>0、AIDE² private 分+预算约束、Moss 三段门）。"准入门=保守差分+回滚"可定为框架默认最佳实践；M9 需支持**对外候选**与**对内自改**两种准入（prime-agent）。
4. **M8 带宽档序得到新样本填充**：SEAL 证明"对 agent 的反馈带宽应独立于评估带宽且越低越鲁棒"——带宽不是单调越高越好，验证了"带宽是配置轴而非优化目标"的抽象定位。
5. **奥卡姆剃刀内置**：Simple Baselines 提示框架应内置"最小基线投影"（IID RS/SCS 退化配置）作为任何复杂配置的对照——可直接做成 recipe。
6. **X2 人有明确价值样本**：Moss（授权门）、Argus（Reviewer 权威+多终端触达）、openresearch-cli（dashboard）——X2 不是装饰。

## 四、对框架材料的修订建议（待 Claude Code 里程碑间隙合入）

**SPEC.md**
1. `Candidate` 增加 `level: L0|L1|L2` 与可选 `verifier_ref`（SEAL 教训：验证器内生时必须显式建模）。（G1）
2. `EvalResult.metrics` 的 key 规范从 split 前缀扩展为 `{split}.{visibility}.{name}`（如 `private.dev.acc`）。（G2）
3. 每个模块 config 增加 `evolvability` 字段，默认 `fixed`；`self_modifiable` 模块的变更强制走 StateMutation + X1 记录。（G3）
4. M8 Protocol 增加 `reliability: {n_evals, cascade_stages, confidence}` 与 `attribution_evidence` 可选字段。（G4）
5. M2 算子清单增加 `aggregate/merge` 类型（输入 = delta + per-item 翻转证据，EvolveNet 模式）；`ExecutorSpec` 增加 `level` 支持跨层异质（AIDE² 双层）。

**CLAUDE.md**
6. 新增不变量：**评估信号默认外生且对被评对象最小泄露**；内生验证器必须显式声明并配外部审计门（SEAL 四条件）。
7. 新增反模式禁令：禁止在 M8/M9 自身代码变更时跳过 X1 记录。

**REFERENCES.md（新增条目）**
8. M2 算子集 → OpenRSI 四算子（github.com/FrontisAI/OpenRSI）；merge 算子 → EvolveNet（arXiv:2608.04968 §4.3）
9. M9 准入门 → SEAL（arXiv:2607.24300 Table 2 四条件）；AIDE² 博客（private 分+预算约束）；EvolveNet §6.3 "gate 不 rank"
10. M5/X1 → prime-agent `/refine`+快照回滚；dgm（arXiv:2505.22954）档案树+功能性存活门
11. X3 评估卫生 → BigBang-v1 decontamination 清单；PAST-Bench（arXiv:2608.04003）三类配对控制与 Mechanism score
12. 元层（可进化性） → MetaSkill-Evolve（arXiv:2607.05297 双时间尺度）；ShinkaEvolve meta 层
13. 方法论/奥卡姆 → Simple Baselines（arXiv:2602.16805 §5/§7）

**ZOO.md**
14. PAST-Bench 列为 P2 benchmark 接入候选（测试记忆通路而非分数）；接入硬要求：支持持久化开/关运行时消融。
15. 新增"最小基线 recipe"（IID RS / SCS）作为所有 benchmark 的强制对照组。

## 五、这批工作的演化图景（一句话版）

- **工程化**（openresearch-cli、argus、moss）：把 autoresearch 做成可运维系统——git 谱系、角色管线、热替换；创新在 X1/X2 而非搜索算法。
- **元层化**（dgm、AIDE²、MetaSkill-Evolve、prime-agent、EvolveNet、OpenRSI）：被优化对象从"解"上移到"求解器/改进策略"——这是 2026 年最清晰的主线，也是我们抽象 G1/G3 缺口的来源。
- **评估科学化**（SEAL、Simple Baselines、PAST-Bench、BigBang-v1、EvolveNet）：社区开始把"评估是否可信"当作一阶研究对象——信号密封、统计可靠性、通路归因、评估卫生。这条线与我们"三层评估协议"的方向完全同频，且给了更锋利的形式化。
- 我们的九模块+六类型恰好覆盖前两条线的工程需求，第三条线要求把 X3 与 M8 可靠性轴补上——**补完后抽象对这批工作达到完全表达力**。
