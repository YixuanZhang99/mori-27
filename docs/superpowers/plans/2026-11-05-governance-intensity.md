# Governance intensity comparison plan

1. Extend M7 profile and agent with an explicit, validated control schedule;
   preserve [0] and the original hard limits by default. Test equal profiles
   except schedule, invalid schedules, hard capacity and frozen resume binding.
2. Exercise both schedules through the public agent with a loopback provider,
   identical synthetic task and fresh isolated ledgers. Independently verify
   control completion, physical/currency receipts, replay and submission.
3. Build a separately frozen, one-shot comparison runner and official scoring
   protocol. Add a trusted pre-import bootstrap and dependency identity; the
   current checkout checks alone do not attest executed code. Gate paid runs on
   exact source, complete local and hosted checks,
   original quiescent CNY authority, data and current pricing. Never infer
   comparison scores from the earlier greedy/population pilot.
4. Run the authorized bounded pilot, publish both quality and cost/overhead,
   retain all failures and state the seed/model limitations. Keep B5 open if
   comparable cost/admission coverage is missing.
