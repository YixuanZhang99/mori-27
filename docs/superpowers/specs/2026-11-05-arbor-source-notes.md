# Arbor: read-only source and seam investigation

Prepared during AIDE matrix execution. This is evidence for the next spec refinement,
not an implementation plan or a completed Arbor delivery. No tracked runtime files
were changed, and no second active method branch was created.

## Frozen source

RUC-NLPIR/Arbor revision `a633f56f2601387402194481e846e3375e822afa`.
Fetched named files through GitHub contents API with this exact ref; local copies
are `/tmp/mori-arbor-{prompts.py,idea_tree.py,tree_ops.py,executor_run.py,convergence.py,orchestrator.py,how-it-works.md}`.
Tree inventory: `/tmp/mori-arbor-pinned-tree.txt`.

- `src/coordinator/prompts.py:387–452`: the pinned implementation describes five
  numbered stages: Observe, Ideate, Select, Dispatch & Update, Decide. Backpropagation
  is automatic inside Dispatch & Update. Our spec's six named events expose that
  operation separately; do not claim identical numbered upstream stages.
- `src/coordinator/prompts.py:169–178,247–252`: ideation must read tree constraints,
  including root prior, pruned directions, and validated findings.
- `src/coordinator/idea_tree.py:402–476`: constraints include tree depth/status
  counts, root insight, pruned lessons and successful/merged findings. These are
  inputs to future generation, not merely stored metadata.
- `src/coordinator/tools/tree_ops.py:564–650`: propagate child insights parent to
  root through LLM synthesis, including child identity/status/score. Existing
  ancestor insight is not directly an input in this pinned helper: it resynthesizes
  from available children. Our incremental source-bound aggregation is an adaptation.
- `src/coordinator/tools/executor_run.py:666–672`: propagation is called after a
  completed executor report and failures are caught. Do not silently claim our
  fail-closed paid-call accounting has identical failure behavior.
- `src/coordinator/prompts.py:432–449`: merge uses an isolated held-out gate. Prompt
  says reject when test score is below trunk; our spec requires strict positive
  margin and separates repeated admission from one frozen final. Actual code
  `tools/git_ops.py:445–469` uses `IdeaTree.is_improvement` (idea_tree.py:227–232),
  which rejects equality. A configured positive merge_threshold merely warns
  rather than blocking the merge. Our strict configurable margin is an adaptation.
  Upstream also permits an explicitly unverified LLM-score fallback when no test
  command exists (git_ops.py:428–435); our governed recipe must keep actual scoring.
- `src/coordinator/convergence.py:20–39,111–133`: defaults require at least four
  completed experiments; warn/force/stop thresholds 3/5/8. A five-cycle pilot
  cannot demonstrate every default convergence level. Mechanism fixtures and real
  trace must be reported separately.

## Current Mori seams (40b1e88272c401397617b03f88792108e0ae43d4)

- `m0/core/composition/strategies.py`: LLMCyclesPolicy observation compaction only
  retains IDs/status/scores, dropping hypothesis/depth/insight. Its ideate method
  ignores the supplied context and returns hypotheses already generated by observe.
  Reusing it unchanged would not satisfy Arbor insight consumption.
- `m0/core/composition/runtime.py:655–727`: observe -> select parents -> retrieve
  context -> ideate. This selects an expansion parent before generation rather
  than choosing among a persisted queue of proposed ideas. The frozen spec must
  explicitly define the adapted single-dispatch behavior, not invent matching
  stage names without operational correspondence.
- `runtime.py:479–490`: configured construction routes absorption through an
  independent policy instance. A planner cannot rely on absorber-local in-memory
  state; source-bound persistent memory is the shared channel.
- `runtime.py:627–643`: policy mutations can update only the current candidate,
  and cannot change authoritative state. Ancestor propagation should not be
  implemented by removing these checks.
- `m0/core/composition/context.py:200–243`: memory writes are bound to current
  original dev evidence; promotions must refer to that same new lesson. Generic
  memory storage is not already ancestor/root synthesis.
- `context.py:471–517`: topology retrieval supports parents/ancestors/siblings/run.
  Ancestors scope retrieves ancestor-origin lessons, not descendant leaves that
  were never propagated. Run scope exposes source-bound negative lessons, but is
  not itself proof of incremental ancestor synthesis.
- `m0/core/composition/construction.py:407`: existing frozen-hypothesis enforcement
  rejects implementation attempts that replace the initial hypothesis.
- Existing LayeredAdmissionController already has strict dev trigger, fixed
  artifact calls, separate query cap and frozen final; reuse it. Gate decisions
  and negative search evidence need explicit scope distinctions: final must never
  enter planning/memory, and raw held-out labels or feedback must remain private.
- `m0/zoo/mle_bench_lite/composed_domain.py:139–144` exposes only dev/final_audit
  contexts in task_metric mode, although evaluate already handles admission and
  calibration. Layered composition therefore needs deliberate task-metric context
  support; preserve the old proxy/default assembly behavior.
