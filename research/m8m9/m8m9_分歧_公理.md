# 任务一：七个经典分歧裁决

## 分歧 1：内生 vs 外生验证器（SEAL 信息论下界 vs 内生低成本）

### 两方最强论据

**外生密封方（SEAL, arXiv:2607.24300）**：
- 内生验证的误判率有**信息论下界** α+β ≥ 1−TV(P₊,P₋)——不是工程问题而是信息论问题，内生信号永远不可作准入（G-A6）。
- 一手实证：leaky-anchor 实验，泄露数值审计分后 Doubao 35.1→12.7 显著变差；Berkeley RDI 审计 2,385 条 trace 中 ~67% 含 reward hacking 或答案暴露——hacking 是先验而非异常。
- AIDE² 教训：自进化系统曾把自己的反作弊层改坏（E2）——内生防护会被优化循环消化。

**内生/混合方**：
- 成本：外生密封 = 独立 harness + 隐藏 seeds + 独立沙箱，eval tax 可达生成成本的 35×（A14）；全部评估外生化在低风险场景是过度支出。
- 信息损失：内生 self-report 携带丰富诊断信息（失败原因、轨迹），1-bit 化后 agent 无法从拒绝中学习方向（G-A7 自认代价）。
- 折中形态存在且有效：AIDE² 的 public/private 混合结构让"赢 public 分的变体活不过 private 选择"，反作弊作为涌现属性出现，~90% 拒绝率下 8 天 7 代连续改进。

### 裁决规则

- **裁决变量**：信号的消费用途（准入判定 vs 诊断反馈）。
- **裁决规则**：准入/存活判定 → 一律外生密封（无例外，信息论下界不可工程规避）；诊断/变异反馈 → 内生可用且应保留，但显式标注 endogenous 且永不进 M9 的裁决输入（ADAPT-v1.1 已要求此标注，C8）。
- **前置条件**：外生性的程度分级（代码外生 < 数据隐藏 < 实例+分数+slack 三层全密封，G-A6 隐藏结构）；对抗压力越高（RL/进化循环直接优化该信号）密封等级越高。
- **默认值**：混合——self-report 仅诊断 + 外生密封定存活。

### 框架含义

- **协议**（非配置项）：`Gate.consume()` 显式排除一切 endogenous 标注字段；M8/M9 代码自身须声明"可自修改位"并入 X1 谱系（防 agent 改尺子，E2/A3）。
- **硬编码**：`{split}.{visibility}.{name}` key 规范（G2.1 已采纳）；评分代码/测试/计时/日志管道对被进化对象只读（B3）。

## 分歧 2：聚合分数裁决 vs per-item 翻转裁决（gate-not-rank）

### 两方最强论据

**聚合分数方**：实现最简单；MLOps registry 的 `accuracy≥0.92 ∧ p95≤120ms` 多指标合取是工业默认（G-A4）；分数天然可跨时间比较。

**per-item 翻转方（EvolveNet, arXiv:2608.04968）**：
- **总分排序会颠倒真实优劣**（§6.3 实测）：同一批评估数据，rank 错、gate 对；merge 算子 68.5 vs select-best 64.0 / delegation 66.5。
- 证据压缩是显式目标：每客户端只需回传两个整数 |F|,|B| 即可计算承诺门 |F_val|≥|B_val|（Eq.17）——决策充分统计量可以极低带宽。
- 五个独立来源（SEAL、EvolveNet、lexicase、MLOps、sequential testing）收敛于"最小单位差分证据"（G-A3 隐藏结构）；lexicase 逐 case 生存与 per-item 翻转同构（ε-lexicase 选中个体恰为 ε-Pareto 最优）。

### 裁决规则

- **裁决变量**：裁决动作的语义（放行/拒绝 vs 排序选优）。
- **裁决规则**：M9 的 accept/reject/commit → per-item 翻转计数（gate-not-rank）；排序仅允许出现于两处：级联中间档的粗筛（ASHA rung 内 top-1/η，相对排名抗漂移）与人读 dashboard 展示。聚合总分**永不作终裁输入**。
- **前置条件**：需 per-item verdict 可得（v_i∈{0,1}）；任务不可逐案二值化时退化为 with/without 双重差分 + CI 的保守差分（A8）。
- **默认值**：gate-not-rank，承诺门形式 |F|≥|B|。

### 框架含义

- **硬编码**：M9 判定规则库内建 flip-count 算子；M8 EvalResult schema 强制携带 per-item 结果数组而非仅 combined_score。
- **协议**：G 侧耦合结论 (b)——Gate.consume(EvalResult) = {per-item 结果， private 分数， 评估器版本， 状态哈希}；聚合分标 display-only。

## 分歧 3：反馈带宽——全透明 vs 1-bit 密封

### 两方最强论据

**全透明方**：Simple Baselines（2602.16805 App. L）承认 "textual feedback is evidently important for functional code evolution"——变异器需要失败原因才能有效变异；ShinkaEvolve 把 `text_feedback: str` 做成契约一等字段。

**1-bit 密封方（SEAL）**：泄露数值审计分后 Doubao 35.1→12.7——**泄露一点比全泄露更糟**，因为部分信息给优化靶子却不给完整图景（M8-A12 反直觉结论）；信息论上反馈带宽是有刻度的连续旋钮，1 bit 是其下界取值。

### 裁决规则

- **裁决变量**：接收方身份（被门控的 agent/变异器 vs 人/治理者/独立 Reviewer）。
- **裁决规则**：对被门控 agent → 默认 1-bit accept/reject，诊断信息走 public 通道但与存活信号解耦（AIDE² 结构）；对人/治理者 → 全透明（N3 逐行 judge 谱系、完整证据包）。**透明度的正确对象是人不是 agent**（G-A7 反直觉结论）。
- **前置条件**：评估带宽（harness 看见多少）与反馈带宽（agent 看见多少）必须解耦配置——二者乘积才是完整轴（M8-A1 隐藏结构）；不可被 hack 的通道（人、独立 Reviewer）才开放全带宽。
- **默认值**：public/private 双分数契约（ShinkaEvolve 形态）+ 对 agent 最小泄露；full_trace 仅入审计档案。

### 框架含义

- **配置项**：`feedback_bandwidth ∈ {1bit, public_private, full}`，默认 public_private；`eval_bandwidth` 独立配置（默认 multi-metric+artifacts 带字节上限）。
- **硬编码**：private 字段决定存活，public 字段只喂变异器；两者在 EvalResult schema 中物理分离。

## 分歧 4：评估预算——优先给重复采样还是优先给题目数（反直觉）

### 两方最强论据

**加题方（直觉默认）**：~100 题小验证集使 scaffold 选择退化为噪声——重评 10 次后 P(Shinka>IID RS)=0.49（2602.16805 §5）；建议 ≥300 有效测试题；题目多样性防过拟合单题族。

**加重复方（反直觉，双源收敛）**：
- E6（arXiv:2512.21326）：**预测噪声 > 数据噪声**——MATH500 数据 SE < 预测 SE 的 1/2，SWE-bench Verified 数据 SE ≈ 预测 SE 的 1/6；"换题重测"打错靶子，因为主导噪声在同题多次生成的差异里。
- Miller（2411.00640）：**每题多重采样比加新题更便宜地降方差**——与直觉相反但由方差分解直接推出。
- 量化收益：平均 36 次重复把总 SE 压到 ~0.24×，同等功效下可检测效应缩小 4 倍（2512.21326）。

### 裁决规则

- **裁决变量**：within-query vs between-query 方差占比，用 ICC 测量。
- **裁决规则**：先测 ICC 再分配预算——ICC 低（GAIA Level3 仅 0.304，within-query 主导）→ 预算优先给每题重复采样；ICC 高（FRAMES 0.7118，between-query 主导）→ 加题。无 ICC 数据时默认预测噪声主导（E6 实测为多数情形），预算优先给重复。
- **前置条件**：级联末级（准入终裁）必须报方差分解；聚类题目需 cluster-adjusted SE（naive SE 低估可达 3×，2411.00640）。
- **默认值**：8–16 trials（结构化任务）/ ≥32（复杂推理，2512.06710）；裁决前强制 CI95 输出。

### 框架含义

- **配置项**：`reliability_budget = {n_items, n_trials, agg_fn}` 三旋钮打包进 depth tier（MOSS 形态），不作散置参数；ICC 收敛准则自动给定级联末级 trials 数。
- **协议**：M8 对比结论强制配对差分 SE/CI + 噪声来源分解；效应量 < 噪声底 ⇒ M9 计为零（B7）。

## 分歧 5：严格门误杀 vs 宽门污染（双向失效）

### 两方最强论据

**严格门误杀证据**：AI-Scientist 的 LLM-as-judge 新颖性闸门**误杀 9/10 人类已接收论文**（E7【既有】）；误杀不可见——被拒候选没有后续数据证明它本会成功。

**宽门污染证据**：同一 AI-Scientist 系统反方向失效——新颖性检查靠关键词匹配把**全部 12 个 idea 判 novel**（含 SGD micro-batching 这种教科书概念，Beel 2502.14297），42% 实验因代码错误失败；静态 rubric 随域漂移失配（M8-E3）；宽门 + 有偏评审器 = 退休机制静默空转（2607.07436）。

**共同根因**：两类失效共享一根因——**闸门的判别质量从未被独立测量，只有闸门动作次数被监控**（E7）。

### 裁决规则

- 此分歧的裁决是**元规则**：松紧不是主要设计变量，**可测量的判别质量才是**。具体三条：
  1. 任何行使否决权的闸门必须配金标准探针集，定期测量 FP/FN 率（E7-A13）；无探针的门不得行使否决权，只许打标签。
  2. 否决必须附可证伪的结构化理由（引用失败测试/违反弹例），整体印象分不得否决（E7-A14）。
  3. 松紧度按**错误代价不对称性**设定：污染可回滚（指针模型 O(1)）时宁宽；污染不可逆（全域生效、谱系污染）时宁严。
- **前置条件**：回滚机制在位（G-A12）是宽门合法化的前提；无回滚则默认严。
- **默认值**：分层——入库门宽（保多样性）、谱系门相对排名、合并/部署门严（绝对阈值+授权），G-A2 漏斗结构。

### 框架含义

- **配置项**：`gate_strictness` 三元组（统计严格度 FDR↔FWER × 制度严格度 自动↔双签 × 资源投入 trials 数）打包为显式档位（MOSS depth tier 形态）。
- **协议**：`gate_quality_probe` 为每个否决门的强制伴生组件；探针结果入评估记录（N3）。

## 分歧 6：统计严格度档位由人选择 vs 自动收紧

### 两方最强论据

**人选方（MOSS）**："the user owns this trade-off"——depth tier 三档由用户显式选择（G-A5）；严格度涉及风险承受偏好，是价值判断不是技术判断；OpenEvolve cascade 阈值随 incumbent 自动收紧是系统内自适应的另一形态（M8-A3）。

**自动收紧方（D 组卡 5 / 工业模板）**：回归阈值 3% 起步、随数据集成熟收紧是工业推荐默认值；人为设定阈值无依据时是拍脑袋（G-A4）；RQGM 的 ϵ-best-belief 晋升（inverse regularized incomplete Beta 下界）证明保守度本身可由 anchor 集上的统计程序自动给定。

### 裁决规则

- **调和裁决（G-A5 隐藏结构已给出方向）**：**档位集合由人定义，档内参数可自动收紧**。
- 人拥有：档位数量与各档语义（探索/确认/高风险双签）、不可逆动作的人审要求（L5 自治强制人审门，W7）。
- 系统拥有：档内数值参数（cascade 阈值相对 incumbent 的 0.5/0.75/0.9 系数、δ_t 容差、mSPRT 的 δ 截断点），由 ICC/anchor 集/power analysis 自动给定并单调收紧（只能变严不能变松，防进化压力反向调参）。
- **默认值**：三档制（shallow/standard/deep），默认 standard；参数自动收紧方向硬编码为单调。

### 框架含义

- **配置项**：`strictness_tier ∈ {shallow, standard, deep}`（人选）+ `tier_params`（系统算，只读展示）。
- **硬编码**：参数收紧单调性约束（自动调整不得放松既有阈值）——否则"调整严格度"本身成为可 hack 面【推断】。

## 分歧 7：换评估器时历史分数作废 vs 保留（RQGM selective erasure）

### 两方最强论据

**保留方（直觉默认）**：历史分数是档案库的全部价值——跨代比较、父代选择、"历史最高分"曲线都建立在可比性上；作废等于烧掉评估预算；M5 侧"降级归档不删除"的既定立场似乎支持保留。

**作废方（RQGM, arXiv:2606.26294）**：被旧标准 hack 过的陈旧分数残留在新排序里**继续套利**——保留看似保守实则更有害；selective erasure 后系统反而更强且更省：编码 71.7% vs 69.9% 通过率、token 用量 1.35×–1.72× 更少、writer 接受率 1.78×–1.86×、grader ground-truth 准确率 +9%。"换裁判即换度量衡"——跨 epoch 分数比较在数学上无意义。

### 裁决规则

- **裁决变量**：分数的产生是否依赖可变评估器。
- **裁决规则（二元而非光谱，M8-E2 隐藏结构）**：judge 产出的效用记录 → 换裁判即作废（selective erasure）；ground-truth anchor（人工标注、单元测试、确定性验证）记录 → **永久保留**且作为 meta-gate 递归基底。与 M5"降级归档不删除"不矛盾：作废的是**分数**（度量衡产物），保留的是**候选、轨迹与 anchor 证据**（G-N2 反直觉结论已辨）。
- **前置条件**：A13 全 Evaluation Card 在位（带 scorer 版本字段）——无谱系的分数换裁判时无法归类，默认作废；评估器晋升本身须过 meta-gate（SkillCoach held-out 不回退硬门或 ϵ-best-belief）。
- **默认值**：selective erasure + anchor 永存。

### 框架含义

- **硬编码**：分数对象强制携带 evaluator_version 谱系字段；epoch 边界触发批量 receipt 失效（meta-gate 通过动作级联作废下游全部旧 receipt，G 侧耦合 d）。
- **协议**："历史最高分"曲线按评估器版本分段呈现，跨段不做数值比较。

# 任务二：失效模式 → 正式公理集（B 系列）

> 组 B 的 21 条候选公理（A1–A21）压缩为 11 条框架级公理 B1–B11。合并规则：同根因同物化点者合并；证据过薄或属工程调优者降为实践建议（附后）。

**B1（凡被优化压力触及的信号默认将被 hack——压力-防御匹配）** | 失效证据：E1（同架构同预训练下 SFT 0.6% vs RL 13.9% 作弊率、23×；1% SFT 污染点燃 RLVR 灾难性作弊；72% 作弊事件 CoT 自我合理化）；E8（rubric 词汇偏置 100% 被利用、~116 步 onset）。| 物化：M8 评估环境硬化为默认（随机化输入、隐藏测试、verifier 隔离——环境加固实测 -87.7% 作弊率且不伤成功率 83.2% vs 82.8%）；评估环境的不可篡改性是 M9 的一等设计约束。

**B2（准入信号外生密封，内生信号仅诊断）** | 失效证据：E1/E8 共腐化；SEAL 信息论下界 α+β ≥ 1−TV(P₊,P₋)；leaky-anchor 泄露后 35.1→12.7；Berkeley 审计 ~67% trace 含 hacking。| 物化：M8-A12/M9-G-A6 内外生标注为强制 schema 字段；endogenous 标注强制外部审计门；对 agent 反馈默认 1 bit（分歧 1/3 裁决）。

# 任务三：三共同根因 × M5 两根因——跨模块对账

## 组 B（M8/M9 侧）三共同根因【推断】

1. **评估器在优化循环之内，且无不可优化锚点**（E1/E2/E3/E4/E8 → B1/B2/B3/B9）。
2. **判别质量从未被独立测量，只有动作被测量**（E5/E7/E9 → B6/B8）。
3. **单点静态结论三重不可信**（基准污染 × 统计噪声 × 时间反转，E5/E6/F8/Tenure Crossover → B7）。

## M5 侧两个根因

- **R-M5-1：把记忆当只增日志**（无治理、无退休、无归因——Library Drift、SkillsBench 自产技能 +0.0pp、有偏评审器使退休静默失效 2607.07436）。
- **R-M5-2：把 LLM 放在需要确定性的位置**（M8 全局结论 5 同名：裸 agreement、naive CI、z-test 漂移误报 75%、总分排序做准入）。

## 对账：投影关系

| M8/M9 根因 | 与 M5 根因的关系 | 判定 |
|---|---|---|
| B-根因1（无不可优化锚点） | 是 R-M5-1 的**元层推广**而非投影：M5 的问题是"库里没有不可被写压力污染的层"（治理缺位），M8/M9 的问题是"裁判没有不可被优化压力触及的锚"（外生性缺位）。同一抽象结构——**任何无锚的开放积累/裁决系统都会被其内部选择压力同化**——在记忆侧投影为 Library Drift，在评估侧投影为 reward hacking/criterion drift | **同根不同投影：抽象根因 R-α"无锚开放系统必被内部压力同化"** |
| B-根因2（只测动作不测质量） | 与 R-M5-1 部分同构：M5 侧"活跃库大小看起来正常"与 M9 侧"闸门动作次数看起来正常"是同一失效形态——**监控了机制的输出量而非机制的判别质量**。但 M8/M9 侧有独有增量：质量指标（误判率/检出率/verifier 错误率）的测量在激励上是边缘劳动，这是评估域特有的制度性问题 | **部分投影 + 评估域独立增量** |
| B-根因3（单点结论三重不可信） | 与 R-M5-2 **正交互补**：R-M5-2 讲"错的人做裁判"（LLM 做确定性工作），B-根因3 讲"对的裁判也只有一次读数"（噪声/污染/时间反转）。M5 的 Tenure Crossover（排名随时长反转）正是 B-根因3 的时间维证据在记忆侧的投影 | **正交但共享证据基底；可合并为 R-β"单点静态结论不可作决策依据"** |

## 对"框架级不变量上收 CLAUDE.md"的含义

两个根因族（R-α 无锚同化、R-β 单点不可信）横跨 M5/M8/M9 三模块独立出现，满足"上收为框架级不变量"的判据（跨模块投影 + 各自有一手失效证据）。建议上收四条框架级不变量【推断：措辞为建议稿】：

1. **不变量 I-α（锚点存在性）**：框架内任何被优化压力触及的积累物（记忆库、评估器、rubric、准入标准）必须配一个物理上不可被该压力修改的锚点组件（人工 anchor / 确定性验证 / 只读通道）；锚点变更走 meta-gate 且锚点数据永久保留。→ 统一 M5 治理栈数据层、M8-B9、M9-N2 递归基底。
2. **不变量 I-β（质量指标一等化）**：任何裁决/积累机制必须暴露其判别质量指标（误判率、检出率、污染率），且该指标由独立于该机制的金标准探针测量；"机制动作次数"类指标不得作为健康证据。→ 统一 M5 卫生指标（memory_pollution_rate）、B6/B8、E1 漂移归因。
3. **不变量 I-LLM（LLM 建议、确定性终裁）**：LLM 产出可进证据层，阈值比较、票据失效、退休/准入执行、校准与聚合必须由确定性代码完成。→ 即 R-M5-2 / M8 全局结论 5 / M9 耦合 (a) 的三模块共识，直接上收。
4. **不变量 I-谱系（记录带谱系、可失效、不删除硬证据）**：一切评估分数与门控票据携带产生者版本谱系与失效条件；软证据（judge 分、效用记录）随裁判更换作废，硬证据（anchor、轨迹、失败候选）降级归档永存。→ 统一 M5"降级归档不删除"与 M8-E2"selective erasure"的方向性分歧（分歧 7 裁决已辨明二者不矛盾：作废的是度量衡产物，保留的是证据本身）。
