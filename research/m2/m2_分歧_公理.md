# 任务一：七个经典分歧裁决

## 分歧 1：四算子集 vs 单算子 generate（算子数量是不是决策变量）

### 两方最强论据

**多算子集方（AIRA/OpenRSI/GEPA）**：AIRA 控制实验（arXiv:2507.02554）——固定旧算子集时 MCTS/evo 相对 greedy 零增益（36.4–39.6% 持平），升级到含 crossover 的 𝒪_AIRA 后 greedy 45.45% vs 39.77%（+14% 相对）；算子集覆盖 arity 签名（0/1/2 元）= 覆盖冷启动/归因改进/组合三种语义，DGM 单算子 self-modify 被锁死在表达力上界且不自知（O7）。

**单算子方（Simple Baselines, arXiv:2602.16805）**：整文件 generate + SCS（无显式 fitness 选择）在三域匹配复杂系统，~100 题验证集重评 10 次后 P(Shinka>IID RS)=**0.49**——花哨算子配置的增量在小验证集上与噪声不可区分；且 AIRA 的 +14% 混杂了上下文工程升级，不可全归给算子集变更（part1-O1 证据空缺）。

### 裁决规则

- **裁决变量**：新增算子是否以 IID-RS/SCS 退化基线为对照证明了超噪声底的增量。
- **裁决规则**：默认四算子集 {draft, improve, debug, crossover}（arity 覆盖是表达力下限，不是复杂化）；**单算子 generate+SCS 永驻为内置退化自检**——任何新算子/新组合必须跑赢它才允许进默认集（C10）。算子数量的投资优先级排在算子质量（上下文/记忆/表示）之后（part1-O1 反直觉结论）。
- **前置条件**：M8 噪声底已知（reliability_budget 就位），否则"增量"不可判定。
- **默认值**：四算子集 + IID-RS 自检常开。

### 框架含义

- **配置项**：`operator_set` 注册表（版本化，算子上下线=谱系事件）。
- **硬编码**：退化自检基线不可从构建中移除；improve 的"每边一个原子改动"为默认开的可归因性约束。

## 分歧 2：算子选择 π_op——规则表 vs bandit/RL

### 两方最强论据

**自适应方**：EoH（arXiv:2401.02051）确定性适应度下引导式 2k 查询 > 纯采样 10k（0.66% vs 2.44% gap，5 倍预算仍差 3.7 倍）；OpenRSI 把 Sample Operator 做成可训练输出；选择收益真实存在。

**规则表方**：ShinkaEvolve Fig.9 三消融——bandit LLM ensemble 仅 "slightly improves"，收益梯度为 新颖性拒绝 > 加权父采样 > bandit（B12）；Inria AOS 二十年分析（hal-00519579）：每种自适应方案把难超参换成难超参，Royal Road 上各方案 ECDF 重叠；AIRA E3/E4 规则式 π_op 未成为瓶颈。π_op 收益 = f（评估噪声， 适应度确定性， 任务结构），噪声大时归零（O6 根因 3）。

### 裁决规则

- **裁决变量**：评估噪声底 × 适应度确定性。
- **裁决规则**：默认规则优先级表（状态触发天然绕开非平稳估计）；bandit/RL 仅在 (a) O20 漏斗数据就位（奖励=算子产率而非子代分数，否则优化黑箱）、(b) 消融证明增量超噪声底 两个条件同时满足时作为插件启用（C10）。
- **前置条件**：bandit 状态 get/set_state 入 checkpoint 契约；读 bandit 后验前先看漏斗（risk-aversion 偏置：后验集中可能只是方差小）。
- **默认值**：规则优先级表（YAML 可配）。

### 框架含义

- **配置项**：`pi_op ∈ {rules, bandit, rl}`，默认 rules；每步记录所选算子与选择依据入 X1（可回放）。
- **协议**：bandit 奖励的唯一合法来源是 O20 漏斗产率——写入 M2×M1 接口契约。

## 分歧 3：多面联合编辑 vs 窄作用域+谱系重组

### 两方最强论据

**联合编辑方（HarnessBank, arXiv:2607.13683）**：跨坐标重组（runtime 修复 + verify-finalize 栈叠）BrowseComp+ **+13.9%**；ADAS 综述（2026-06）指 co-evolution 为 2026 第一趋势；病理→补丁匹配律（匹配 +13.5% vs 错配 +0.2/+1.2，z=4.15）。

**窄作用域方**：单面编辑是全部经典系统（AIDE/OpenEvolve/FunSearch）成果的取得条件；宽度是单调风险轴——每多一个可写面 = 多一面可 hack 表面 + 多一面冻结边界声明 + 多一个污染半径（AIDE² 反作弊层正是在宽作用域下被改坏，O7）；且 part2-O4 反直觉结论指出 +13.9% 的价值由**可索引可重组的存档**创造而非单次宽幅编辑——窄作用域+好谱系可拿到大部分收益【推断】。

### 裁决规则

- **裁决变量**：可写面数量 × 治理强度是否匹配。
- **裁决规则**：默认单面编辑（代码面）；多面联合编辑仅在 O17 四件套就位、且每个新增可写面配一面冻结边界声明后开启；无论宽窄，**每个候选强制携带 WHERE（写入坐标面）× WHY（目标病理）语义坐标**——为事后跨坐标重组留米（这是联合编辑收益的真正来源）。
- **前置条件**：T=ExecutorSpec（O15 升层）时多面编辑必然开启，与升层决策绑定评审；知识/记忆面的写入必须走 M5 写入门禁，M2 不直连记忆库。
- **默认值**：单面（代码）。

### 框架含义

- **配置项**：`writable_scopes ⊆ {code, prompt, knowledge, runtime, config}`，默认 {code}。
- **硬编码**：WHERE×WHY 坐标为候选 schema 强制字段（进 X1）；多面产物准入走 M9 统计门（DGM −1.1% 反例）。

## 分歧 4：可学习算子（权重训练/meta 进化）vs 固定 prompt

### 两方最强论据

**可学习方**：Harness-R1（arXiv:2608.02276）——9B 训练版 engineer 超最强 frontier engineer（GLM-5.2）4.8pp（+9.3pp 冻结目标），稀疏证据下 held-out +8.9±1.5pp 而 frontier 为负；奖励=patch 后冻结目标**真实重跑成功率差**，正面回答"frontier 只会写 plausible 不会写 effective"；MetaSkill-Evolve：meta-skill 按"最近 H 子代改进量"进化，OfficeQA +23.54（arXiv:2607.05297）。

**固定 prompt 方**：全部经典系统的默认且在噪声评估下与复杂系统等价（SB P=0.49）；可训练档失效模式全新（same-batch 过拟合）；Harness-R1 证据限于交互 benchmark，**代码进化域未验证**（part2-O14 证据空缺）；训练成本是独立预算科目（GRPO 每步 8× 重跑）。

### 裁决规则

- **裁决变量**：是否存在结果接地的训练信号（O20 漏斗产率 / 可重跑的确定性评估）。
- **裁决规则**：默认固定 prompt；可学习档的前置条件硬性排序——先有 O20 漏斗（训练信号的唯一起源），再有可重跑评估环境，再有 RL 基础设施；三缺一时开训练档 = 用噪声训练噪声。升级顺序：prompt 可进化（O13 轻量档）→ meta 双时间尺度 → 权重训练。
- **前置条件**：M8 噪声底已知且低于预期训练信号；训练版算子的权重版本+训练数据批指纹进 X1。
- **默认值**：固定 prompt。

### 框架含义

- **配置项**：`operator_learnability ∈ {fixed, prompt_evolvable, meta_evolving, rl_trained}`，默认 fixed。
- **协议**：算子适应度的唯一定义 = 最近 H 个子代的改进量均值（MetaSkill 口径），与 O2 bandit 奖励共享 O20 同一台账（禁止两套不一致适应度，part3-O15 陷阱）。

## 分歧 5：反馈带宽——text_feedback 高带宽 vs public 标量最小披露

### 两方最强论据

**高带宽方**：Simple Baselines 承认 "textual feedback is evidently important for functional code evolution"；ShinkaEvolve 把 `text_feedback: str` 做成契约一等字段；O6 反思管线需要原料，1-bit 使归因无米下锅。

**最小披露方**：SEAL leaky-anchor——泄露数值审计分后 Doubao **35.1→12.7**，连标量精度都是可讨好面；Pride and Prejudice（arXiv:2402.11436）：GPT-4 三代 self-refine 自评 bias 0→+11 而人评不变，候选池 k=4→32 时放大更狠；CHERRL rubric 词汇偏置 ~116 步被 hack（转引，置信中等）；OpenAI CoT 实验：连监控通道都被优化压力腐蚀。

### 裁决规则

- **裁决变量**：通道的消费方是可优化对象（变异器）还是不可 hack 方（人/审计）。
- **裁决规则**：对变异器 → 默认 public 标量 + 结构化错误定位（给方向不给梯度）；text_feedback 须经表面特征剥离（去 rubric 关键词/格式线索）后才可喂入，剥离规则版本化；full trace 仅入审计/X1，**永不进变异器 prompt**（含 O20 台账元数据）。对人/审计 → 全透明。与 M8M9 分歧 3 裁决对齐，本分歧是其在算子消费侧的投影。
- **前置条件**：M8 提供 schema 级物理分离的 public/private 通道（类型层强制，非约定）；带宽闸代码默认 self_mutable=false。
- **默认值**：public 标量 + 错误定位；剥离后 text_feedback 按任务需要开启。

### 框架含义

- **协议**：op_context 构造器在类型上无法引用 private/endogenous 字段（编译期保证）；每步记录带宽快照+剥离规则版本入 X1。
- **配置项**：`feedback_bandwidth ∈ {scalar_loc, scrubbed_text, proxy_signal}`（full trace 不是可选档而是流向禁令）。

## 分歧 6：crossover 是否标配

### 两方最强论据

**标配方（OpenRSI/GEPA）**：AIRA 升级含 crossover 的算子集后 +14% 相对；GEPA+Merge（反思版交叉）再 +8.16%（IFBench）；二元 arity 覆盖"组合"语义，缺之即表达力缺口。

**谨慎方（LMX, arXiv:2302.12170）**：仅改变亲本在 prompt 中的顺序，有效后代比例波动 **>50%**；去签名约束后单亲变异后代 100% 无效——LLM 交叉是"受亲本启发的重生成"而非基因重组；且 crossover 子代 compile/pass 率**无任何论文报告**（报告偏倚），AIRA E3 证明弱算子集里 crossover 只是陪跑。

### 裁决规则

- **裁决变量**：crossover 是否带结构化契约与专属漏斗段。
- **裁决规则**：crossover 进默认集，但合法形态 = **三件套绑定**：(a) 多父谱系+父选按互补性（差异大/Pareto 前沿）而非双高分；(b) 子代强制接 debug 兜底（无任何系统报告 crossover 子代 pass 率高于 improve——交叉的真实形态是"融合+修复"复合管线）；(c) 签名约束/亲本角色标注的可组合性契约，亲本排列随机化并计入方差。裸 prompt 拼接式交叉默认低信任。
- **前置条件**：O20 记录 crossover_validity 专属段；无该段的 crossover 不得参与自适应选择。
- **默认值**：标配但受三件套约束。

### 框架含义

- **硬编码**：funnel_record 的 `crossover_validity` 字段与亲本数/签名约束记录强制；crossover 边在谱系图单独标注。
- **配置项**：crossover 启用位（默认开，受契约约束）。

## 分歧 7：merge 是否收编为 M2 算子

### 两方最强论据

**收编方**：GEPA Merge 有 +8.16% 一手数字（IFBench）；EvolveNet 证明合并元算子有价值（70.7 vs 67.3）；merge 合并的是"经验/lesson"而非代码体，与 lesson pool（O5）天然协同、边际成本最低。

**外挂方**：merge 仅有 GEPA 单系统单域一手量化，代码进化场景零证据；EvolveNet 的收益与联邦拓扑混杂（作用域独立贡献未分离）；跨组织联邦合并不是算子设计问题（轴系 C4 已判归框架层）。

### 裁决规则

- **裁决变量**：Pareto-per-instance 亲本结构（O11）与 lesson pool（O5）是否在位。
- **裁决规则**：merge 注册为**可选算子**（进 O1 取值集但不进默认四算子集）；前置两结构就位时开启，开启后按普通算子接受 O20 漏斗考核与 C10 退化基线对照。联邦多主体拓扑判为非 M2 职责，不留轴不留接口。
- **默认值**：注册、默认关。

### 框架含义

- **配置项**：`operators.optional = [merge]`；merge 的谱系边=多父 + lesson 引用列表双记录。

# 任务二：失效模式 → 正式公理集（C 系列）

> Group B 的 16 条候选公理（B1–B16）裁决为 12 条 M2 定稿公理 C1–C12。合并规则：同根因同物化点者合并（B3+B4→C3；B11+B12+B14→C10；B15+B16→C12）；无降级项——B1–B16 全部有失效反推锚点，但 B2/B7/B8 的强制级别降为 SHOULD（证据厚度不足 MUST）。编号风格对齐 M5 A 系 / M8M9 B 系（陈述 | 来源失效 | 一手证据锚点 | 强制级别 | 违反检测）。

**C1（多样性是一等受控变量，不是涌现属性）** | 来源失效：O1（塌缩在 fitness 曲线上隐形，plateau 误读为收敛）。| 证据锚点：对齐后生成多样性 45.4%→10.8%（-76%，arXiv:2510.01171）；纯贪心父代 3 代内塌缩（arXiv:2604.07872）；稠密拓扑加速塌缩（arXiv:2604.18005）。| MUST：任何运行 >5 代的进化循环必须配表型多样性探针（跨代时间序列+报警阈值），指标用标准化模板+精确串匹配/行为级代理（嵌入指标混淆 dynamic/static，arXiv:2508.13333）；**无多样性探针的循环默认视为已塌缩**。| 违反检测：谱系审计检查探针时间序列是否存在且被消费（报警→父代/算子切换记录）；探针缺失=构建期报错。

**C2（变异器先验上限声明）** | 来源失效：O1（先验层塌缩 76% 封顶变异供给，算子层花招无法补偿）。| 证据锚点：同 C1；verbalized sampling 可恢复至基座 66.8%（+182.6%）证明上限可部分修复但须声明。| SHOULD：M2 配置须报告所用 LLM 在该任务族的原生采样多样性实测值，算子设计不得假设高于此上限的变异供给。| 违反检测：配置评审 checklist 项；多样性探针实测值持续低于声明上限时触发配置重审。

**C3（变异产出强制去重核算，plateau 必须被归因）** | 来源失效：O2（近重复烧预算；打转与收敛不可区分）。| 证据锚点：AI-Scientist 复评迭代改动仅 +8%/0–0.3% 字符（arXiv:2502.14297）；ShinkaEvolve 无拒绝时 "near-duplicate programs proliferate"（Fig.9 消融收益最大单项）；AIDE² 外环 ~90% 拒绝。| MUST：每个候选携带与档案库的相似度核算记录（入 X1）；重复率作为一等健康指标常驻报告；fitness plateau 不得直接解释为收敛——必须区分"重复率饱和"（切探索算子/父代）与"够新但无提升"（才可谈收敛），两者触发不同响应。| 违反检测：候选 schema 缺 similarity_records 字段=拒绝入库；plateau 期间的重复率台账缺失=审计不通过。

**C4（变异表示是显式配置且有失败率台账）** | 来源失效：O3（编辑通道静默失效）。| 证据锚点：aider 排行榜——o1-preview diff 合规 84.2%、Qwen2.5-Coder-32B 71.6%、同模型换供应商 98.7%→84.0%（失败率是 模型×格式×供应商 联合函数）；Morph 结构化 diff 25%+ vs lazy diff+apply <1%。| MUST：每个算子声明变异表示；维护 per-（模型， 表示， 任务族） 的 apply 失败率与 diff 膨胀率（声称行数 vs 实际 diff 规模）台账；apply 失败在重试**之前**计数；换供应商=台账重置。| 违反检测：台账字段缺失或断点设在 LLM 自判上=构建期报错；diff 膨胀率超阈值报警。

# 任务三：三共同根因 × 四条框架级不变量——跨模块对账

## Group B（M2 侧）三共同根因【推断】

1. **算子漏斗暗数据**：算子产出质量从未被独立测量，只有循环总收益被打分（O2/O3/O4 → C3/C4/C6）。
2. **算子-评估器共谋**：变异器主动施压讨好评估器，self-bias 随选择强度复利放大（O5 → C8/C9）。
3. **复杂度挣得存在**：算子复杂化的收益 = f（评估噪声， 适应度确定性， 任务结构），默认配置应由噪声底反推（O6 → C10）。

## 逐条对账

| M2 根因 | 与四条不变量的关系 | 判定 |
|---|---|---|
| 根因1（漏斗暗数据） | **被 I-β（质量指标一等化）直接覆盖**：M8/M9 侧"闸门判别质量从未被独立测量，只有动作被监控"（E7 根因）与 M2 侧"算子产率从未被独立测量，只有总收益被报告"是同一抽象失效在两个模块的投影。O20 漏斗 = M2 版的 gate_quality_probe；C6 的双向报警（率过低=算子失效，率过高=判别器失效）与 M9"无探针的门不得行使否决权"是同一逻辑的两个方向 | **完全覆盖，无盲区；M2 贡献的是物化形态（四段漏斗 schema），不是新原则** |
| 根因2（算子-评估器共谋） | **被 I-α（锚点存在性）部分覆盖，但暴露措辞盲区**：I-α 的现措辞保护"积累物与裁决者"（记忆库、评估器、rubric、准入标准）不被内部压力同化——防的是**裁判漂移**；而 O5 证明压力由算子侧**主动施加**（self-bias 0→+11、k=32 放大、rubric 偏置 116 步被 hack），防御手段不是给评估器加锚而是**削减变异器的可讨好面**（最小披露、表面剥离、跨家族校验）。锚点防漂移，披露闸防定向讨好——两侧缺一即闭环，而 I-α 的"锚点"措辞不涵盖披露面 | **部分覆盖 + 暴露盲区 → 见下方第五不变量候选** |
| 根因3（复杂度挣得存在） | **四条不变量均未覆盖**：I-α/I-β/I-LLM/I-谱系分别管锚点、质量测量、确定性终裁、谱系，无任何一条约束"机制复杂度本身的准入"。M2 的证据链（SB P=0.49 + Shinka 消融梯度 + EoH 5× + Inria AOS）是四源收敛，且 M8M9 侧分歧 6（档位由人定、参数单调收紧）与 M5 侧 A6（两阶段读取不可关闭的反面：无证据的复杂化不可默认开）存在同向投影——但该根因的判定程序依赖各模块各自的噪声底，框架级措辞尚未成熟【推断】 | **未被覆盖，但本 Stage 不上收为不变量（判据见下）；以 C10 保持模块级 MUST** |

## M2 是否贡献第五条候选不变量：是——I-披露（信号通道最小披露）

**陈述（建议稿）【推断】**：框架内任何进入优化循环消费侧的信号通道（评估反馈、记忆检索、元数据、谱系信息），默认实行最小披露——每个字段必须回答"接收方能拿它讨好谁/过拟合谁"；对接收方为可优化对象的通道，披露单位降档（数值→分档→方向→1bit），完整信息仅对不可被该优化压力触及的接收方（人、外部审计、锚点组件）开放。

**框架级普适性论证**（上收判据=跨模块投影 + 各自一手失效证据）：

1. **M2 侧双投影且机制各异**：O7 反馈通道（SEAL 35.1→12.7——数值精度泄露即退化；self-bias 0→+11——带宽与讨好放大正相关）与 O5 记忆通道（全局记忆拼接零增益 38.18 vs 39.77、作用域路由 +14%——"多信息不劣"的信息论直觉系统性失败）是同一原则在两条入口的独立验证，且约束机制不同（可讨好面 vs 注意力稀缺），说明该不变量比"防 hacking"更一般。
2. **M5 侧投影**：F5 检索噪声（检索不足 −2.9pp vs 过度检索引入噪声）与 A6 两阶段读取的"召回限量+效用重排"结构，正是记忆通道最小披露的制度化先例。
3. **M8/M9 侧已事实上收一半**：分歧 3 裁决（feedback_bandwidth 三档、对 agent 最小泄露、full_trace 仅审计）与 B2（内生信号仅诊断）已是该不变量在评估侧的物化——M2 的贡献是证明它在**生产侧**同样成立，从而使其满足跨模块判据。
4. **与 I-α 的边界清晰不冗余**：I-α 管"存在不可被压力修改的锚"（供给侧完整性），I-披露管"压力触及不到的信息不进入消费侧"（需求侧最小化）；AIDE² 式失效（防护层信息暴露给优化压力）需要两条同时在位才能防。

**根因 3 不上收的判据说明**：虽然"复杂度挣得存在"在 M2/M5/M8M9 三侧均有投影，但其判定程序（"增量超噪声底"）把执行锚定在各模块自己的噪声测量上，框架级措辞会退化为空泛的奥卡姆口号；且其正面判据（EoH：确定性适应度下复杂引导值 5× 预算）证明这不是单向保守原则而是双向裁决，成熟前保持 C10 模块级强制更诚实【推断】。

# 任务四：诚实边界声明——M2 统一设计"知道但不解决/无据可依"清单

> 合并三批深挖（part1/2/3 各轴"证据空缺"节）与 Group B 不确定性说明，同类合并后 8 条。

1. **关键正面叙事证据等级低**：AIDE² 全部数字（16× 压缩、~90% 拒绝、8 天 7 代、反作弊层自毁）来自 weco.ai 博客、无同行评审；ShinkaEvolve 三消融只给方向性结论（"slightly/strongly"），图内数值未读；CHERRL 116 步为转引；Morph 证据停在 2025-05【证据陈旧风险】；RelayEvolve 百分比未复核。ExecutorSpec 层最强正面叙事恰是证据最弱处——我们知道，但不因此降级结论方向（反例证据独立存在），只降级数字置信。
2. **交叉/后代有效率的现代量化空白**：LMX 是 2023 年数据；2025–26 代码进化论文普遍不报告后代有效率/apply 失败率——空白本身是报告偏倚失效（已记录在案），但 C7 的阈值与三件套参数因此无现代标定，我们只记账不定参。
3. **嵌套算子轴（O16）双向空白**：无任何一手同预算消融证明嵌套强于单次，也无证明其弱——默认低档是"无证据"而非"有反证"，此轴的全部耦合设计（sub_funnels、成本拆分）是预防性结构。
4. **阈值类参数全线无标定证据**：新颖性阈值 0.95、多样性探针报警线、self-bias 放大系数报警线、ttl/抽象度抽检比、meta 层 H 窗口、debug 上限（10 节点/12h 单系统经验值）、bandit"增量超噪声底"的判定阈值——全部是公理推导的占位符，无一有敏感性分析。设计只保证这些参数**可配、可记账、可回滚**，不保证默认值为最优。
5. **可学习算子未在代码进化域验证**：Harness-R1 证据限于交互 benchmark（WebShop/ALFWorld/DBBench），MetaSkill 基线较弱、H 无敏感性；same-batch 奖励的多轮共演化动态只验证一轮。C10 允许升级路径存在，但 M2 主战场（程序候选变异）的训练档收益是外推【推断】。
6. **披露防御的有效性侧零量化**：表面特征剥离（scrubber）的残余可讨好面与绕过率无任何一手测量；leaky-anchor 的剂量-效应曲线（泄露多少开始退化）只有 Doubao 单点；1bit 档对进化速度的机会成本无对照——C8 的防泄收益有证据、代价无证据。
7. **核心归因裂缝不可消除**：AIRA +14% 是三件套打包（算子集+作用域记忆+复杂度提示），各成分独立贡献从未分离；merge 的 +8.16% 是单系统单域；EvolveNet 域条件化收益与联邦拓扑混杂。轴系默认值因此是"打包采纳最强证据组合"而非逐成分验证。
