# M1 Policy（全局搜索策略）模块 · 2025–2026 前沿扫描（Group C：轴系外维度）

扫描窗口 2025-05 → 2026-08，优先 2026。格式参照 /mnt/agents/output/research/m4/groupC_frontier_new.md。假定背景轴系为经典策略维度：探索/利用权衡（ε-greedy、softmax 温度、UCB）、亲本选择公式（适应度比例/锦标赛/幂律）、相位调度（固定 schedule）、停止判据（预算/停滞）、分配意图（模型/算子路由）。以下只列轴系**之外**的候选维度。数字均引自一手来源（arXiv 原文、官方博客）；未复核处标【未复核】，外推处标【推断】。

## (1) 前沿系统策略层精读（一手锚点）

- **AlphaEvolve**（arXiv:2506.13131，DeepMind 白皮书，2025-06）：策略层 = 数据库 sample(parent, inspirations) → prompt_sampler 组装 → LLM diff。亲本/灵感采样按 MAP-Elites+岛屿启发式平衡探索利用，**但采样公式本身是人工固定的**；双档 LLM（Flash 吞吐 / Pro 质量）按静态配比调用。策略层无任何学习/进化成分——策略固定、artifact 进化。
- **ShinkaEvolve**（arXiv:2509.19349，Sakana AI，2025-09；ICLR 2026 poster）：策略层三件一手组件：(a) 亲本采样 = 幂律性能加权 × 新颖性加权（后代少者优先），显式平衡探索/利用；(b) **UCB1 bandit 选 LLM 集成**，奖励=相对父代/基线的改进幅度（非平稳自适应）；(c) **meta-scratchpad**：周期性从成功个体提炼高层优化策略，反写进变异 prompt。圆打包 <150 次评估达 SOTA。策略层语义："选择策略参数在线自适应 + 策略经验文本化积累"，但策略结构仍固定。
- **GEPA**（arXiv:2507.19457，2025-07；ICLR 2026 Oral）：亲本选择 = **per-instance Pareto 前沿频率加权随机采样**（候选出现在实例 Pareto 前沿的次数正比于选择概率）。一手消融：Pareto 采样 vs 贪婪 SelectBest 最高 +8.17%、聚合 +6.4%；贪婪一轮后即陷局部最优。停止判据=纯 rollout 预算耗尽；相位无调度（单一循环）。策略贡献在"选择公式的实例粒度化"。
- **RelayEvolve**（arXiv:2608.05651，2026-02/08）：**相位调度首次被显式建模为带状态优化问题**。Grow–Deepen bandit（recent-window UCB）在 block 粒度分配便宜模型轨迹；**Relay Gain**（质量-多样性 relay bank 的边际改进，单调子模目标）统一驱动三件事：轨迹分配、handoff 时机、移交种子集选择（贪心子模，(1−1/e) 保证）。一手对照：call 级 bandit 路由**近视失效**（表现不稳定），固定切换点 Fixed-switch 一致劣于自适应 handoff；前 20 代便宜/强模型进展比 0.82–1.01×；4 benchmark × 3 预算 11/12 均值最高。停止判据 = Relay Gain 持续饱和或预算耗尽。
- **EvolveNet**（arXiv:2608.04968，2026-08-05）：联邦式协作进化。策略层新义务：**给每个 client 的 proposer 指派异质搜索角色**（conservative repair / independent exploration / adversarial audit，按 client index 分配，防止并行分支坍缩到同一类编辑）；server 端 scope-typed 聚合 + 逐项行为门控 + 失败回滚（回滚恒指向上一共享 harness 而非最优 client）。K 条并行轨迹成本 = 最慢分支（比串行低 1.9–5.4×）。策略从"单主体轨迹控制"扩展为"多主体角色编排 + 合并门控"。
- **AIDE²**（weco.ai 博客，2026-07-14；基座 AIDE arXiv:2502.13138）：AIDE0 的树搜索策略层极简且**全人工**：先写 5 个"尽量互不相同"的草稿，之后每步以固定启发式二选一——debug 一个随机 buggy 叶子 或 improve 全树最优解；亲本选择纯贪婪（best-so-far）。外层 RSI 循环在 100 步、8 天内进化出 AIDE85：自主重写内层搜索算法、prompt 缩 16×、奖励黑客率 63%→34%（KernelBench held-out），且泛化到 4 个外部 benchmark。**策略（何时 draft/debug/improve、选哪个父节点）本身成为被进化的代码对象**，但进化机制是 hill-climbing（better-only 接受）+ 外层 LLM，不是学习到的参数化策略。
- **Harness-R1**（arXiv:2608.02276，2026-08-03）：**编辑策略首次被参数化并用 RL 训练**。9B harness engineer 经 cold-start SFT + 在线 GRPO 训练，对冻结 target agent 的运行时（context 构建/工具中介/动作验证/恢复逻辑四个生命周期钩子）生成可执行 patch；奖励 = 同 batch 重跑的实现成功率差 Δ。WebShop/ALFWorld/DBBench 平均 44.3%→53.6%（+9.3）；迁移到 20 个未见 target 模型全部正增益、1270 个 held-out 任务提升。证明"搜索/干预策略是可学习能力"，但其策略对象是 agent harness 而非进化循环的亲本/相位决策。【边界案例】
- **LoongFlow**（arXiv:2512.24077，2025-12-30）：把 LLM 进化形式化为 MDP ⟨𝒞,𝒜,R,π_θ⟩，动作空间 = 语义修改操作（rewrite/debug/optimize），LLM 即随机策略 π_θ(a|s)；Plan-Execute-Summarize 把转移核分解为 blueprint→code→reflection 三步，记忆 ℳ_t 积累 insight 供 Planner 检索。**"分配意图"（选 rewrite 还是 debug）由 Planner LLM 在 prompt 内决定**，无外部学习机制。
- **AdaEvolve**（arXiv:2602.20133，2026-02-23）：**单一标量信号统一三级自适应策略**。累积改进信号 G_t（平方归一化改进的 EMA）同时驱动：Level 1 岛内探索强度 I_t（停滞自动加探索，无需手动重启阈值）；Level 2 跨岛 bandit 资源分配（**全局归一化奖励** r=(f′−f\*)/f\*_global 消除"差岛偏好"，衰减累计 + UCB）；Level 3 停滞触发 "System 2" meta-guidance——LLM 生成全新高层解题战术重定向搜索；全岛停滞（G_t≤0.02）自动 spawn 新岛。185 个问题统一超参，圆打包 n=26 达 2.636（超人类 SOTA 2.634、AlphaEvolve 2.635）。
- **EvoX**（arXiv:2602.23413，UC Berkeley，2026-02/03）：**搜索策略本身作为可进化对象的双层进化**。策略 S 形式化为 C_S(𝒟_t)→(x_par, π, ℐ)（选亲本、选变异算子 refine/structural/free-form、选灵感集）；策略数据库 ℋ 存 (S_j, J_j, ϕ_j)，J = Δ·log(1+s_start)/√W 为部署窗口内的进步率信号；停滞时 LLM 以历史策略+种群描述子 ϕ(𝒟_t) 为条件变异出新策略。近 200 任务上多数优于 AlphaEvolve/OpenEvolve/GEPA/ShinkaEvolve。案例：run 内自发经历 random→greedy→分层多目标→UCB+局部精修 的相位序列。**策略谱系（哪个策略在什么种群状态下有效）成为一等持久数据**。
- **Squeeze Evolve**（arXiv:2604.07725，2026-04）：verifier-free 进化的**成本路由策略**。用模型内蕴置信度/答案多样性（logprob，零成本）把每个重组组路由到贵模型/便宜模型/非 LLM 轻量聚合三档；初始化质量是最终精度最强预测因子（AIME 上祖先/重组角色互换差 23 分）。API 成本降 1.3–3.3×、固定预算吞吐升 ~10×，ARC-AGI-V2 97.5% @$7.74/task。
- **SeaEvo**（arXiv:2604.24372，2026-04/05）：策略意图的**语义空间化**。SA 模块在生成前先诊断失败、指定策略方向；SLN 周期性总结"有效/饱和/未探索"策略家族并指导变异；SER 按行为互补性（而非 fitness 或文本相似度）检索灵感。系统优化任务平均 +21%。亲本/灵感选择从 fitness 空间移到**策略语义空间**。
- **EvoDiverse**（arXiv:2606.10587，2026-06；ICML 2026）：parallel tempering 多温度池，β 梯即**探索强度的连续分层**，池间 Metropolis-Hastings 交换；同 prompt 消融（仅 β 不同）仍 +12%/+19% Top-10 AUC（JNK3/GSK3β）。温度调度=探索/利用轴的"分布化"取值。
- **旁证**：Harness-1（arXiv:2606.02373，2026-06）——RL 训练搜索 agent 的 harness 化策略，held-out 迁移增益 +7.2~+32.8（均值 +17.0），"策略学习操作于域通用搜索状态，故迁移性强"；《Automated Discovery Has No Universally Superior Harness》（arXiv:2607.18235，2026-07）一手证明**不存在跨任务普适最优策略/harness**，为"策略-任务适配"维度提供阴性对照。

## (2) 逐项新发现卡片

### 卡片 1：策略作为可进化对象——双层进化与策略谱系库（EvoX）
- **发现**：搜索策略（亲本选择+算子选择+灵感集组装规则）不再是固定人工旋钮，而是带 (策略, 进步率信号, 部署时种群状态) 记录的**可变异、可选择、可替换的种群对象**；LLM 按历史策略表现+当前种群描述子生成下一代策略。
- **来源+日期**：arXiv:2602.23413，2026-02/03（v2 2026-03-16）。
- **量化证据**：近 200 任务多数优于 AlphaEvolve/OpenEvolve/GEPA/ShinkaEvolve；案例研究中单 run 内策略自发经历 random→greedy→分层多目标→UCB+精修的相位演化（各相位增益 +0.119/+0.022 等）。
- **为何在既有轴系之外**：经典轴系把"探索/利用权衡、亲本公式、相位调度"当作**设计时固定参数**；EvoX 把它们打包成一个可进化单元并维护其谱系。2023 前的 meta-EA/参数控制文献只调数值超参，不存在"用 LLM 生成全新策略代码/规则"的取值。

### 卡片 2：策略作为可训练参数化对象——RL 训练的策略编辑者（Harness-R1 / Harness-1）
- **发现**：干预策略（何时、在哪个生命周期钩子、做何种 patch）被参数化为 9B 模型并用 cold-start SFT + 在线 GRPO 训练，奖励=实现任务成功率差；学习到的策略跨 20 个未见 target 模型全部正迁移。
- **来源+日期**：arXiv:2608.02276，2026-08-03；旁证 Harness-1 arXiv:2606.02373（+17.0 均值 held-out 迁移）。
- **量化证据**：44.3%→53.6%（+9.3，三 benchmark）；fine-tuned target 上再 +5.0；20/20 未见模型正增益。
- **为何在既有轴系之外**：这是"**策略可学习性**"的最强取值——策略权重经梯度/RL 更新，而非 bandit 调参（ShinkaEvolve/AdaEvolve 的 UCB 只更新选择统计量，不更新策略的表示与生成能力）。对照 M2 轴系中"算子可学习性"，M1 侧对应物 2026 才首次出现。

### 卡片 3：策略作为被 RSI 重写的代码——外层循环进化内层搜索策略（AIDE²）
- **发现**：内层 agent 的搜索策略（draft/debug/improve 决策、亲本选择、context 组装）作为**可执行代码**被外层 autoresearch 循环以 better-only 爬山进化重写；100 步 8 天超过人类两年手调 agent（AIDE85 vs AIDE_human：MLE-Bench Lite 0.721 vs 0.708，ALE-Bench 1790 vs 1511）。
- **来源+日期**：weco.ai 博客《AIDE²: First Evidence of Recursive Self-Improvement》，2026-07-14【一手博客，非同行评审】。
- **量化证据**：MLE-Bench Lite 0.673→0.739/0.721；KernelBench reward hacking 63%→34%；4 个 held-out benchmark 均泛化。
- **为何在既有轴系之外**：策略治理维度——策略有**版本谱系**（AIDE0→AIDE47→AIDE85）、接受判据（held-out 聚合分）、自我指涉层级（外层策略改进内层策略）。经典轴系无"策略生命周期管理"概念。

### 卡片 4：相位调度 = 带状态优化问题，非日历表（RelayEvolve）
- **发现**：相位切换（便宜模型探索→强模型精修）不由固定预算比例决定，而由**relay bank 边际增益（Relay Gain）饱和**触发；同一子模目标同时决定分配、时机、移交集。一手阴性对照：call 级 bandit 近视失效；固定切换点一致次优。
- **来源+日期**：arXiv:2608.05651，2026-02-15。
- **量化证据**：11/12 设置均值最高；Fixed-switch 全败于自适应 handoff；早期 20 代便宜/强进展比 0.82–1.01×。
- **为何在既有轴系之外**：旧"相位调度"轴的取值是时间表（何时切换）；新维度是**相位切换的状态依赖触发机制 + 相位间移交物的显式估值**。与 M4 卡片 2（档案移交）互为镜像：M4 看移交什么，M1 看何时切换与为何切换。

### 卡片 5：多主体策略编排——异质搜索角色指派防坍缩（EvolveNet）
- **发现**：并行进化分支若不干预会坍缩到同类编辑；EvolveNet 给每个 client proposer 显式指派互补搜索角色（conservative repair / independent exploration / adversarial audit），这是**跨主体层面的探索/利用分工**——探索/利用权衡从"单主体内的采样分布"提升为"多主体间的角色配置"。
- **来源+日期**：arXiv:2608.04968，2026-08-05。
- **量化证据**：等预算集中式 population 67.3% vs EvolveNet 70.7%（BIRD，14 胜 9 负）；DS-1000 合并 harness 超最强单 client +9.0；集中式无门控链式进化直接崩溃回滚。
- **为何在既有轴系之外**：2023 前岛屿模型的"迁移率/拓扑"是旧取值，但"**指派异质搜索意图以防止并行分支同质化**"是 LLM 时代新问题（LLM 先验使独立分支趋于收敛到相似解）。

### 卡片 6：策略意图的语义空间化——先定方向再生码（SeaEvo / LoongFlow / AdaEvolve Level 3）
- **发现**：三个系统独立收敛到同一模式——变异前先由 LLM 在**自然语言策略空间**做决策（SeaEvo SA 诊断失败→指定策略方向；LoongFlow Planner 生成 blueprint；AdaEvolve Level 3 停滞时生成全新解题战术），再落到代码。分配意图从"选哪个算子"升格为"选哪条用自然语言描述的搜索方向"。
- **来源+日期**：arXiv:2604.24372（2026-04）、2512.24077（2025-12）、2602.20133（2026-02）。
- **量化证据**：SeaEvo 系统优化 +21% 平均；AdaEvolve 185 问题统一超参、圆打包 2.636 超 SOTA。
- **为何在既有轴系之外**：旧"分配意图"轴管算子/模型选择；这里是**在意图与执行之间插入显式的 NL 策略层**作为可检索、可聚类、可标"饱和"的一等对象。

### 卡片 7：统一标量信号驱动多级策略（AdaEvolve）——策略各层共享一个奖励语义
- **发现**：探索强度、跨岛资源分配、meta-guidance 触发、新岛 spawn 全部从同一累积改进信号 G_t 推导；一手指出"差岛偏好"陷阱并用全局归一化（除以全局最优而非局部历史）解决。
- **来源+日期**：arXiv:2602.20133，2026-02-23。
- **量化证据**：185 任务统一超参优于开源基线；4/6 数学任务达/超人类或 AI 最优。
- **为何在既有轴系之外**：轴系把探索强度、资源分配、停止/重启判据分属不同轴；AdaEvolve 证明它们可以共享**单一奖励语义**——轴间耦合机制本身成为设计维度。【推断】可归为"策略信号架构"轴：每层独立信号 vs 全局统一信号。

### 卡片 8：成本作为策略目标函数的一阶项（Squeeze Evolve / RelayEvolve）
- **发现**：模型选择策略的优化目标从 max fitness 变为 max fitness s.t. 美元/token 预算；路由粒度细化到"重组组"级，置信度作为零成本路由信号。
- **来源+日期**：arXiv:2604.07725，2026-04。
- **量化证据**：成本降 1.3–3.3×；AIME 角色互换差 23 分（初始化质量主导）。
- **为何在既有轴系之外**：旧轴系的"分配意图"不含成本项。但与 M4 卡片 7 一样证据分散在系统论文实现细节中，无专文消融。

## (3) 结论

### 候选新轴清单（按证据强度排序）

1. **策略可学习性轴**（对照 M2 算子可学习性）。定义：策略的表示与参数是否被学习/进化更新，更新机制是什么。候选取值：人工固定（AlphaEvolve/AIDE0）→ bandit 在线调统计量（ShinkaEvolve UCB1、AdaEvolve）→ 策略代码被外层循环爬山进化（AIDE²）→ 策略作为种群对象被 LLM 变异进化+谱系库（EvoX）→ 策略参数化并经 SFT+RL 梯度训练（Harness-R1/Harness-1）。证据锚点：EvoX 200 任务占优、AIDE² 8 天超人类两年、Harness-R1 +9.3 且 20 模型迁移。**建议收编，最强候选**。理由：多点一手证据、梯度分明、直接决定 M1 模块接口（策略是否需要可训练参数槽）。
2. **策略谱系与版本治理轴**。定义：策略版本如何记录、评估、接受/回滚、跨循环层（内层/外层/ meta）引用。候选取值：无版本（单策略）→ 谱系库带部署状态标注（EvoX 的 (S,J,ϕ) 记录）→ better-only 接受+held-out 聚合判据（AIDE²）→ 门控+回滚协议（EvolveNet 行为门控回滚）。证据锚点：上述三家。**建议收编**。理由：一旦策略可变（轴 1 取非固定值），治理即成必需；2023 前文献无"策略版本治理"概念（经典 EA 的参数自适应无版本语义）。
3. **相位触发的状态依赖机制轴**。定义：相位切换/停止由日历（预算比例、固定代数）还是由搜索状态信号触发。候选取值：固定 schedule → 预算耗尽停止（GEPA）→ 边际增益饱和触发（RelayEvolve Relay Gain）→ 停滞检测+meta 干预（AdaEvolve G_t≤τ 触发 System 2 / 新岛 spawn）。证据锚点：RelayEvolve 11/12 + Fixed-switch 全败的对照。**建议收编**。理由：RelayEvolve 提供一手阳性+阴性对照，是"停止判据/相位调度"旧轴装不下的机制维度（旧轴只有取值，无"触发信号语义"）。
4. **多主体策略分工轴**。定义：探索/利用权衡在多个并行进化主体间如何配置。候选取值：单主体（无）→ 同质并行分支 → 异质角色指派防坍缩（EvolveNet 角色 proposer；分布式 Red Queen 的对抗角色 2605.27130）→ 成本档分工（RelayEvolve/Squeeze Evolve 便宜/贵模型角色）。证据锚点：EvolveNet 70.7 vs 67.3 + 角色消融。**建议收编，但与 M4"档案分布与合并轴"对齐命名**（同一分布拓扑问题的策略侧投影）。理由：LLM 先验导致并行分支同质化是 2023 前不存在的问题。
5. **策略-任务适配/迁移轴**。定义：策略是否被证明任务依赖、是否跨任务/跨模型迁移。候选取值：假定通用（多数系统）→ 一手证明无普适最优（2607.18235）→ 跨模型迁移验证（Harness-R1 20 模型；AIDE² 跨 benchmark 泛化）→ 条件化策略生成（EvoX 按种群描述子 ϕ 条件化）。证据锚点：2607.18235 阴性对照 + 各家迁移实验。**建议作为横切评估协议而非独立轴**——它是"策略可学习性轴"的评估属性，单独立轴证据不足。
6. **成本感知策略轴**。定义：策略的目标函数是否显式含 token/美元成本项。候选取值：无成本意识 → 预算约束（RelayEvolve B）→ 边际成本路由（Squeeze Evolve 置信度路由，1.3–3.3× 节省）。**建议与 M4 经济学轴合并为框架级横切约束，不单独立轴**。

### 看似新、实则旧轴取值的东西
- **ShinkaEvolve 亲本幂律×新颖性加权、GEPA per-instance Pareto 频率采样**：是"亲本选择公式"轴的新取值（公式层面创新），不构成新轴。GEPA 的 +6.4%/+8.17% 消融是亲本公式轴上最强的一手量化。
- **EvoDiverse 温度梯、AdaEvolve 探索强度 I_t**：探索/利用权衡轴的新取值（连续温度参数化 / 信号驱动强度），非新轴。
- **LoongFlow 的 MDP 形式化**：把已有概念包装成 MDP 记号，策略本身仍由 prompt 内 LLM 决定，无新机制。不构成新轴，但提供了轴系形式化语言（⟨𝒞,𝒜,R,π_θ⟩）。
- **UCB1 选 LLM（ShinkaEvolve）、置信度路由选模型（Squeeze Evolve）**：均属"分配意图（模型路由）"旧轴取值；RelayEvolve 一手证明 call 级路由近视，才把"路由粒度"问题升格为轴 3/4 的组成部分。

### 阴性发现（以为存在但 2026 不存在）
1. **"策略作为可训练对象"在进化循环内部仍无第二家**。Harness-R1/Harness-1 训练的是 agent harness 编辑/搜索操作策略，不是进化循环的亲本选择/相位调度策略；对"用 RL 训练 M1 策略本身（亲本选择、停止判据）"的检索无任何一手命中。EvoX/AIDE² 均为 LLM-进化而非梯度训练。对照 M2 的"算子可学习性有专文"，M1 侧梯度训练版策略是 2027 空位。
2. **跨任务策略迁移的基准/协议不存在**。各系统只在自家论文里报迁移数字（Harness-R1 20 模型、AIDE² 4 benchmark），无任何共享的"策略迁移 benchmark"或标准协议；检索 "search strategy library reuse across tasks" 零命中。对照 M2"算子共享生态不存在"。
3. **策略谱系的通用表示/格式不存在**。EvoX 的 (S,J,ϕ) 记录、AIDE² 的版本链、EvolveNet 的回滚协议各自私有，无"策略版本+治理接口"的可移植规范；与 M4 阴性发现 1（档案合并协议不存在）同构。
4. **成本感知的策略消融专文不存在**。所有成本论述散落于系统论文实现细节（Squeeze Evolve 最接近但成本是目标非自变量）；无论文以"策略的成本项"为主变量做对照实验。
