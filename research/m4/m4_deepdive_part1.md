## P1 档案拓扑结构

### 1. 取值表

### 2. 隐藏结构

- **"Database 即算法"是本轴的真正命题**：FunSearch 的 cluster-softmax、OpenEvolve 的 MAP-Elites×岛、GEPA 的 per-instance Pareto——选择压力全部编码在档案的物理结构里，而非在选择公式里（GA 综合 1）。推论：M4 不是被动存储层，拓扑选择本身就是搜索算法的半壁江山；**拓扑档案 vs 单池的差异 = 选择压力分布的差异**，换拓扑≈换算法。反例锚点：OpenEvolve 把选择策略硬编码进 `ProgramDatabase`（"换策略需改源码"，GB M4-3/GA 卡 1.3）——它把"Database 即算法"从口号变成了锁定：结构与策略焊死，F-B2 要求的"仅换供给函数做因果对照"在该实现上不可能。
- **拓扑的真实比较维度不是"哪种强"，而是"失效传播半径"**（B 组根因 4）：单池下塌缩/污染瞬时全局化（VRP 纯贪心 3 代塌缩，arXiv:2604.07872）；岛拓扑把失效半径限制在单岛内（重置/迁移还可清岛）；树拓扑无驱逐故污染永久驻留但谱系完整可召回（F-B3）。默认 grid×islands 的本质是"双缓冲器冗余"而非"双机制叠加增益"。
- **组合拓扑的隐藏成本**：grid×islands 意味着每个候选要同时被两个结构索引（岛标签+胞格坐标），checkpoint/合并/驱逐都要双记账；LoongFlow 的 feature map 与 elite archive 联动替换（GA 卡 1.9）展示了一致性维护的复杂度——这是组合形态鲜被消融的原因之一【推断】。
- 实现陷阱：`tree` 与 `grid×islands` 的差异在报表上隐形——两者 best 曲线可完全一致，差异只在 plateau 之后（树保留回退分支，网格已把 stepping stone 格内替换掉，CMA-MAE 的 threshold dynamics）。判定拓扑是否工作必须看 P19 的供给熵与跨岛距离，不能看 best 曲线。

### 3. 反直觉结论

**档案结构的主要增量来自"存在档案"这一比特，而非拓扑的精巧程度——但拓扑决定失效时的爆炸半径**。DGM 消融证明"有 archive vs 无 archive"显著、AIDE² 证明单链（档案≈1 bit 结构）在严格评估下也够到 RSI L1、Simple Baselines 证明噪声评估下一切拓扑都退化为随机搜索（P=0.49）——三者合起来：拓扑精巧化的收益区间被夹在"评估足够严格"（下界，×P15）与"失效传播半径需求"（上界，多岛=隔舱）之间。选拓扑的正确问题不是"哪个跑得更快"，而是"哪个死得可控"。

### 4. 与其他模块接口

- **进 X1**：候选携带拓扑坐标（island_id / 胞格坐标 / 树节点深度）；拓扑变更（岛繁殖、重置）本身是谱系事件。
- **×P9**：拓扑即多样性的物理承载——选 islands 即选择"用隔离买多样性"，选 grid 即选择"用胞格竞争买多样性"，两者对 P9 的默认值构成不同。
- **×P15**：任何非 single_pool 拓扑的启用条件是跑赢单链/SCS 退化投影且增量超 M8 噪声底。
- **×P19**：拓扑健康（跨岛距离、格覆盖率、树分支熵）是健康探针的监控对象；无探针的复杂拓扑视为不可治理。
- **消费 M3**：matrix 形态的 per-instance 表维护成本（GEPA 85–90%）须与预算轴联立声明（F-B9）。

### 5. 证据空缺

- **六种拓扑之间无任何同预算干净对照**——现有"证据"全部是各系统各跑各的（不同任务、不同评估、不同预算），收敛形态（grid×islands）是生态趋同而非消融结论。
- AIDE² 单链证据为厂商博客级，无评审、无消融表细节；其"单链也够"的结论依赖"外环评估严格"这一未公开细节的配置。
- 树拓扑的容量无界 vs 网格的限容在同一任务上的对照不存在（DGM 消融只对比"有/无 archive"，未对比"树 vs 网格"）。

## P2 前沿定义

### 1. 取值表

| 取值 | 机制展开（怎么工作） | 量化证据（一手数字+来源） | 何时选（前置条件） |
|---|---|---|---|
| best_so_far（单点指针） | 全部历史压缩为一个最优指针；最省实现最易解释 | **禁止作默认**：M4-6 机制解剖——无回退、无多样性记忆、无对照能力；ShinkaEvolve Fig.9 hill climbing 曲线"初期最强、快速 plateau"即单峰指纹；DGM w/o archive 消融显著退化（arXiv:2505.22954 §4.3） | 永不默认；仅作为 P15 退化对照的投影形态存在 |
| cell_elite（胞格精英） | 每个 MAP-Elites 胞格存最优，前沿=全体胞格冠军的集合；前沿大小=格覆盖数 | OpenEvolve `get_best_program(metric)`+同格替换取优（database.py 一手）；LoongFlow 每格只留最优且与 elite archive 联动替换 | 默认档（非逐实例场景）。前置：descriptor 可信（P6）；评估噪声已配重评（否则胞格精英是噪声幸存者，Justesen 2019 重评后空格） |
| pareto_per_instance | 前沿="在至少一个验证实例上取得最优"的候选集合；粒度细到实例级，天然多峰 | GEPA 消融：**Pareto 选择策略 +6.4%**（arXiv:2507.19457）；代价一手明确：总 rollout（6,438/678/6,858/2,157）vs 纯训练 rollout（737/79/558/269）差一个数量级，**~85–90% 预算花在 per-instance 验证表维护**，作者自承须"动态选择验证子集"（future work） | 逐实例评估场景（每个候选天然产出分数向量）；且预算可承受全量/动态子集重评；实例须按信息量加权（F-B10，防易实例主导） |
| tree_leaves（全体保留） | 无前沿计算——树本身即前沿，最优=树上最高分；回退能力最强 | DGM §3"archived solutions can serve as stepping stones that result in improvements much later"；消融方向性显著 | deceptive landscape/长程重构；配合 P19 浓度监控防采样稀释（M4-3a） |
| none（全档案即前沿） | 不筛选不压缩，"发现即入档"；排序只在消费者（meta agent/LLM）的阅读视野里隐式发生 | ADAS：DROP F1 +13.6、MGSM +14.4%、跨域 GSM8K +25.9%（arXiv:2408.08435）；但 Simple Baselines 指出 ~100 题小验证集下 ADAS 与 IID RS 无显著差异（P=0.49）——none 形态的增量以评估可靠性为前提 | 消费者是 LLM（可自由阅读长档案）且档案增长受 token 预算约束（隐性治理负债）时；研究原型期可用 |

### 2. 隐藏结构

- **前沿粒度与评估严格度的匹配原则是本轴核心（重点展开）**。三条证据构成一个二维判定：(a) GEPA +6.4%——逐实例评估天然产出分数矩阵时，细粒度前沿（per-instance Pareto）把"哪个候选在哪个实例上强"的信息无损保留，值得付 85–90% 的维护税；(b) AIDE² 单链——外环评估为固定美元预算+private 分数（严格、昂贵、低噪声），粗粒度前沿（单链）即足够，因为评估质量代偿了档案结构的信息保留职能；(c) SB P=0.49——评估噪声大（~100 题）时，任何粒度的前沿都不产生超噪声的增量。**升档判据**（何时从 cell_elite 升到 pareto_per_instance）：①评估输出天然逐实例（升级边际成本≈0）；②实例间判别力差异大（存在"只有个别候选能解"的难实例，粗粒度会系统性丢失其专属候选）；③预算充足到维护税不超阈值（F-B9 要求声明占比上限）。**降档判据**：评估单标量、或噪声底下（重评存活率低）时，细粒度前沿只是更贵的噪声陈列柜——Justesen 的"重评后空格"说明胞格席位已被噪声占据，粒度越细被噪声劫持的席位越多（M4-5c：噪声实例上的"最优"是 lucky sample）。
- **前沿定义决定亲本采样骨架**（×P8 的隐藏耦合）：pareto_per_instance→覆盖比例采样；cell_elite→胞格分层采样；tree→分数×子代数加权。换前沿定义不换采样骨架=结构错配（GEPA 的 +6.4% 是"前沿+采样"联合体的消融，不可全归给前沿定义本身【推断】）。
- **"无前沿"不是"没有结构"而是"结构外包给消费者"**：ADAS 的 none 档把筛选压力转移给 meta agent 的注意力——档案增长的代价是 prompt 变长（GA 卡 1.7 标注隐性治理负债），即 none 档的治理成本以 token 形式延迟结算（C5 横切约束落点）。
- 实现陷阱：best_so_far 在报表上伪装成"收敛成功"（plateau 被误读为完成任务，GB M4-6）；单点档案连自诊断数据都不留存——诊断所需的多样性数据恰是被单峰结构丢弃的数据。

### 3. 反直觉结论

**更细的前沿粒度不是单调更优——它是"信息保留"与"噪声劫持表面积"的 trade-off，且维护成本与选择收益不成正比**。直觉认为 per-instance Pareto 是"最公平最细"的前沿；GEPA 自己的数字（85–90% 预算税）与 QD 噪声文献（重评后空格）共同证明：粒度每细一档，被 lucky sample 占据的席位就多一倍，预算税就重一档。匹配原则的完整表述：**前沿粒度应与评估严格度同升同降——评估能分辨多细，前沿才配保留多细**。AIDE² 与 GEPA 看似矛盾（单链够 vs +6.4%），实为同一规律两端：严格昂贵评估→粗粒度够；逐实例天然矩阵→细粒度值回票价。

### 4. 与其他模块接口

- **×P8（公式归 M1）**：前沿定义决定 M4 暴露给 M1 的采样骨架种类；本轴只声明"哪种骨架可用"，权重公式在 M1。
- **×P10**：前沿表示精度与维护预算联立声明（F-B9）；pareto_per_instance 档必须同时声明动态子集降粒度的触发阈值。
- **×P20**：前沿席位≠供亲资格——低置信席位（单评噪声实例上的最优）可留档但供亲位关闭（F-B10 末句/F-B15）。
- **消费 M8**：评估噪声底是粒度匹配的输入；M4 无法独立于 M8 决定档位（GB M4-8 跨模块共管失效）。
- **进 X1**：前沿成员资格随时间变化（入/出前沿事件）须留痕——前沿是时变集合，不是属性。

### 5. 证据空缺

- "粒度×严格度"匹配原则是三系统间接证据的归纳【推断】，无任何工作以"前沿粒度"为自变量做同任务对照（GEPA 未消融 cell_elite 档，OpenEvolve 未消融 Pareto 档）。
- GEPA +6.4% 混杂了覆盖比例采样（P8），前沿定义的独立贡献未分离。
- AIDE² 单链的评估严格度细节（private 分数构成、重评频率）未公开，"严格评估代偿粗档案"的机制链条缺一环。
- 易实例主导的定量测量（Pareto 席位在易/难实例上的分布）在 GEPA 原文与后续文献中均未见（GB 不确定性说明 2）。

| 动态繁殖 | K 不是常数而是可生长结构：stagnation_threshold=100 触发 island spawn，spawn 策略 ∈ {initial, best, archive_random} | ShinkaEvolve `enable_dynamic_islands`（config.py【一手源码】）；**繁殖触发阈值与 spawn 策略同样无消融** | 长程 run 中 stagnation 可检测（P19 在位）时；把"何时加岛"从超参变为受控响应 |

### 2. 隐藏结构

- **岛数谱系 10→5→3→2 是时间线而非剂量-反应曲线**——这是本轴最必须诚实展开的证据空缺。四个系统的 K 值按发表时间单调递减（FunSearch 2023→OpenEvolve 2025→LoongFlow→ShinkaEvolve 2025-09），但该递减混杂了至少四个共变因子：①部署规模递减（140 评估器→单机）；②任务从数学发现转向样本效率优先（K=2 的系统恰好主打 <150 样本 SOTA）；③迁移机制成熟（迁移越频繁，所需隔离数越少——交换代偿隔离）；④新颖性拒绝等替代多样性机制出现（ShinkaEvolve 的多样性主要由新颖性闸承载，岛的负担减轻）。**没有任何一手同预算消融把 K 作为自变量扫描过**（GB M4-4/GA 空缺 1 双重确认）——K=5 默认值的真实地位是"惯例中位数"，不是"被验证的最优点"。
- **K 与迁移率、迁移周期构成不可分离的三维超参面**（×P4）：K 大+迁移少 ≈ K 小+迁移多，在"全局多样性"这一观测量上可能不可区分；A/B 成本随 K 线性增长，这正是该面从未被扫描的经济学原因【推断】。
- **K 的健康判据在岛间不在岛内**（F-B7）：岛内 best 曲线正常不代表岛在独立演化——"岛各自 best 曲线不同"与"岛在趋同"在曲线中段不可区分；有效观测只有跨岛表型距离时序。K 是否够用的正确答案来自 P19，不来自 K 本身。
- **岛划分维度的隐性失配**（GB M4-4 失效 c）：岛本应按行为/策略聚类隔离，实际实现多按入档时间/哈希随机分桶——名义 K=5，实质"单池加随机标签"。此时测得的"K 不敏感"会被错误归因为岛模型无效【推断】。
- 实现陷阱：动态繁殖的 spawn 策略（initial/best/archive_random）实质是"新岛的创始者选择"，与 FunSearch 重置后的 founder 选择同构——繁殖和重置在"从哪取 founder"上共享同一个未消融子决策。

### 3. 反直觉结论

**最强的样本效率系统用最小的岛数（K=2），最大的生产系统用最大的岛数（K=10）——K 的最优值可能是预算/并行度的函数而非任务难度的函数**。直觉认为"难题需要更多岛保持多样性"；谱系证据指向相反方向：ShinkaEvolve 在 K=2 下用 <150 次评估超过 AlphaEvolve，靠的是迁移高频（interval=10）+新颖性闸，而 FunSearch 的 K=10 与其 155 进程部署同阶。**K 的真实角色是"匹配并行硬件的隔离粒度"，多样性由别的机制（P9）兜底时 K 可以很小**【推断】——这把"岛数"从算法超参降格为系统工程超参，也解释了为何无人消融它：在固定机器数下扫 K 没有生产意义。

### 4. 与其他模块接口

- **×P4**：K 与迁移率/周期共成三维超参面；默认值组合（K=5, rate=0.1, interval=10~50）应作为**联合配置**被消融或整体接受惯例，不做单维调优。
- **×P19**：K 的治理判据（跨岛距离时序、岛间 best 差距）是健康探针的专属段；跨岛距离单调下降→触发迁移率下调/岛重启（F-B7）。
- **进 X1**：岛创建/繁殖/重置事件进谱系；候选的 island_id 字段（P7 契约）的语义依赖本轴的划分维度声明（F-B8）。
- **消费 M3**：K 与可用并行 worker 数联立；K 超并行度无意义。

### 5. 证据空缺（诚实展开）

- **K 的一手同预算消融在整个文献中不存在**——四系统配置是唯一"证据"，且 10→5→3→2 的谱系是时间相关非因果。默认值 K=5 的置信度是全部 20 轴中最低的一档，应标注"待 P15 框架内首验"。
- 动态繁殖（stagnation_threshold=100、三种 spawn 策略）零消融；threshold=100 的量纲（代数？无改进步数？）对任务尺度的敏感性未知。
- 岛划分维度（行为隔离 vs 随机分桶）从未被任何系统声明或测量——"名义岛模型，实质随机标签"的失效在公开文献中无一次被检测到（可能正因无人测量，GB M4-4c 为结构风险记录）。
- K 与并行度的耦合假设（上述反直觉结论）纯【推断】，无一手支撑。

### 2. 隐藏结构

- **迁移的本质是通信拓扑，因此它继承了通信拓扑的塌缩定律**（M4-4 机制展开，重点）：多智能体辩论域的一手证据（arXiv:2604.18005，ACL 2026 Findings）证明**稠密通信拓扑加速早熟收敛，塌缩来自交互结构而非模型能力**。岛间迁移在图论上与辩论通信同构——迁移率上调=通信拓扑变稠密=收敛加速（向单峰）。由此给出**迁移过早失效的机制链**：①某岛产生局部最优→②迁移把它复制为全局模板（环形拓扑下 O(interval) 内传遍所有岛）→③各岛变异器以同一模板做近亲小改（O2 的原地打转被跨岛同步化）→④跨岛表型距离骤降，隔离名存实亡。**迁移的双重身份——多样性的赎回渠道 vs 塌缩的广播信道——取决于时机：被迁移者是否已经"值得广播"**。阶段感知（F-B8）的机制含义即此：早期各岛尚无独特积累，迁移无害也无益；中期迁移是赎回多样性的主渠道；后期高频迁移把最后的岛间差异磨平。固定周期（FunSearch 4h、OpenEvolve 50 代）与演化阶段无关，是"待证默认"的精确含义。【迁移性标注：2604.18005 证据在多智能体辩论域，向岛模型迁移标【推断】，GB 不确定性说明 1】
- **复制非移动+migrated 标记+逐字查重是迁移的三件套，缺一则机制变质**（LoongFlow 实现的隐含公理）：移动（非复制）会把源岛的精英抽空=变相驱逐；无 migrated 标记则同一候选沿环反复迁移=变相全局广播；无查重则同一副本多代重复注入=prompt 预算浪费。这三件套在任何系统论文中都未被消融，是工程惯例的非显式知识。
- **重置与迁移的替代关系（dim06 §3.7）有更深的结构性理由**：重置是**不可逆**操作（被杀岛的积累永久丢失，违 F-B5"不可逆须附可恢复路径"），迁移是可逆的（副本可去重、源候选仍在）——开源复现生态集体转向迁移，与 B 组根因 3"不可逆操作跑在延迟证据前面"的失效模式一致【推断：生态收敛于可逆操作是隐性公理 F-B5 的实证】。
- 实现陷阱：异步架构下迁移的陈旧注册（×P12）——FunSearch 已知"prompt 生成后岛被重置/迁移"的竞态并**刻意忽略**（代码注释一手）；忽略竞态在 K=10/低迁移率下近似无害，但在高迁移率+小 K 下陈旧注册率上升，该近似何时失效无人测量【推断】。

### 3. 反直觉结论

**"多交换信息"与"保持岛间差异"不是 trade-off 的两端而是同一失效的两种速度**——直觉认为迁移率需要"调优到平衡点"；M4-4 的机制分析表明迁移率的真实语义是"塌缩速度旋钮"：rate=0 是永不塌缩也永不收敛，rate 越大塌缩越快（通信拓扑定律）。所以正确的治理方向不是寻找静态最优 rate，而是**把迁移率做成跨岛距离的递减函数**（F-B7：跨岛距离单调下降即下调迁移率）——交换机制应是闭环受控的，开环固定参数的任何取值都是待证配置。

### 4. 与其他模块接口

- **×P3**：K×rate×interval 三维超参面；联合默认值（K=5, rate=0.1, interval=10~50）。
- **×P12**：异步 DB 唯一同步点下，迁移事件的注册时点与 prompt 生成时点存在竞态（陈旧注册）；FunSearch 刻意忽略的先例不等于安全。
- **×P19**：跨岛表型距离时序是迁移率的闭环控制信号（F-B7）；迁移事件台账（谁迁到谁、何时、副本是否被采）常驻记录。
- **进 X1**：migrated 标记是谱系字段——迁移副本的"跨岛谱系边"须与变异边区分（与 P16 的"异源谱系边"同构）。
- **×P20**：被迁移候选若后续被判污染，其所有迁移副本须可枚举（F-B3 祖源级召回在岛间的投影）。

### 5. 证据空缺（诚实展开）

- **迁移率/周期的一手消融与 P3 同样不存在**——0.1/50 与 0.2/10 两组惯例值从未被同任务对比；"迁移替代重置"是 dim06 工程结论，无论文级对照。
- **迁移过早失效（M4-4b）在 LLM 进化域无一手测量**——稠密拓扑塌缩证据在多智能体辩论域（arXiv:2604.18005），迁移性标【推断】；LLM 进化中"迁移何时过早"的判定阈值（跨岛距离？代数比例？）无任何系统报告。
- 阶段感知迁移（F-B8）是纯公理，零实现先例。
- 动态繁殖的 spawn 策略三取值（initial/best/archive_random）从未被对比。

## P5 等价类聚簇

### 1. 取值表

| 取值 | 机制展开（怎么工作） | 量化证据（一手数字+来源） | 何时选（前置条件） |
|---|---|---|---|
| signature（逐测试得分向量） | signature=逐测试得分向量排序元组；同 signature 进同一 cluster，簇内保留多实现、均匀采样；亲本采样=先按 cluster_softmax 抽簇（温度退火 T0=0.1、period=30000 随已注册程序数线性退火）再簇内均匀 | FunSearch 官方仓库 programs_database.py/config.py【一手源码】：`cluster_sampling_temperature_init=0.1, period=30000, num_islands=10` 配套 | 逐测试评估场景（分数向量天然存在）；任务是"同分不同实现"有价值域（程序等价类丰富，如数学函数搜索） |
| embedding_bin | 用嵌入向量分桶近似聚簇；与 P9 新颖性闸共用嵌入通道（一份嵌入两处消费） | 无直接一手系统先例；间接证据：ShinkaEvolve/OpenEvolve 嵌入相似度去重阈值 0.99 两系统一致（GC/GA），说明嵌入通道已在档案层就位，聚簇是零边际成本扩展【推断】 | 评估单标量（无 signature 可算）但嵌入索引已在位时；粗粒度去重即可满足的场景 |
| none | 不做等价类归并；去重/多样性完全交给网格胞格竞争（P1）或新颖性闸（P9） | 隐含基线：OpenEvolve/ShinkaEvolve/GEPA/DGM 均无等价类聚簇——**FunSearch 是唯一一手系统** | **默认值**。grid×islands 在位时聚簇功能冗余（胞格竞争已做同格归并）；per-test 评估不可用时唯一合法档 |

### 2. 隐藏结构

- **signature 聚簇是"评估指标直接当 descriptor"的极端形态**（×P6 的交汇点）：它把逐测试得分向量同时用作准入依据、等价关系、采样权重三重角色——一份评估数据三处复用，这是 FunSearch 的隐藏效率来源【推断】，也是其脆弱点：评估噪声直接污染等价关系（同一程序两次评估落入不同 cluster，等价类不再是等价类）。FunSearch 场景评估确定性高（程序执行+精确评分），该隐患未爆发；噪声评估场景下 signature 聚簇会把噪声实例化为"伪多样性"【推断】。
- **聚簇的真实功能是供给函数的分层，不是去重**：cluster-softmax 先抽簇再簇内均匀，实质是"先选行为模式、再选实现"的两级采样——把 top-k 贪心的单峰供给改写成分层供给。这与岛模型（先抽岛再岛内采样）同构：**聚簇=无地理隔离的逻辑岛**。FunSearch 同时拥有物理岛（K=10）与逻辑岛（簇），双分层是其供给函数的真实形态。
- **簇内均匀采样是隐含的反精英公理**：同 signature 的多实现不取最优而均匀采——承认"同分实现间的差异在未来可能重要"，与 DGM 的 stepping stone 论据（分数×(1+子代数) 保证全体非零被采）同族。
- 实现陷阱：温度退火 period=30000 以"已注册程序数"为时钟，异步架构下该时钟是非确定性的（注册顺序依赖评估完成顺序，×P12）——复现时换异步策略会静默改变退火曲线【推断】。

### 3. 反直觉结论

**档案去重的最优粒度可能不是"语义相似"而是"得分相等"**——直觉认为等价类应按行为/语义定义（嵌入距离）；FunSearch 的 signature（得分向量排序元组）证明：在评估确定的任务上，"在所有测试上得分完全相同的两个程序"是比"嵌入相近的两个程序"更有用的等价类——前者保证行为差异为零（在同一评估下），后者只保证文本相近。但这是一条**评估确定性的函数**：评估噪声一大，signature 等价类即刻碎裂（同程序不同簇），反而不如粗粒度的嵌入分桶稳健。等价关系的粒度应与评估噪声匹配——与 P2 的粒度匹配原则同构。

### 4. 与其他模块接口

- **×P6**：signature 是 descriptor 的极端取值；grid 在位时聚簇与胞格功能重叠（默认 none 的理由）。
- **×P9**：embedding_bin 档与新颖性闸共用嵌入索引（档案侧提供索引，闸的执行在 M2-O8）。
- **×P8**：聚簇在位时 M4 暴露的采样骨架变为两级（簇级 softmax+簇内均匀），M1 注入点相应分层。
- **进 X1**：簇成员关系是时变的（同簇实现增删），簇 id 入谱系字段。

### 5. 证据空缺

- signature 聚簇从未被消融（FunSearch 无"去聚簇"对照）；其对最终结果的独立贡献未知。
- embedding_bin 无任何系统先例，纯设计外推。
- 温度退火参数（T0=0.1, period=30000）无论证；异步时钟的非确定性影响未测量。

|---|---|---|---|
| evaluator_metric | evaluator 输出的任意 metric 直接充当网格维度，binning 由框架内部完成——"低成本高价值"：无需手工选特征 | OpenEvolve config.py/database.py【一手源码】，特征维度可插拔；AlphaEvolve 白皮书佐证方向："即使只关心单指标，多指标进化反而更好"（不同指标下优解结构多样，注入 prompt 刺激多样性，§2 一手） | **默认值**。评估器已输出多维指标（正确性/运行时/内存/长度等）；无人工领域知识可编码 descriptor 时 |
| handcrafted | 人工设计行为/复杂度描述子（2023 前 QD 主流：步态特征、行为轨迹哈希等） | 2023 前 QD 文献主流形态；LoongFlow 教训：descriptor **退化为代码长度/字符差异的浅层代理**（dim05 卡片）——手工/浅层 descriptor 与真实行为差异脱钩后，网格退化为随机分桶（与 M4-4c 岛标签失效同构） | 领域有公认行为度量（机器人、游戏 AI）；且 descriptor 质量可被 P19 监控验证时 |
| semantic | plan 嵌入/假设类别作 descriptor——档案从"行为网格"升级为"假设网格"；与 P18 档案语义表示共用 plan/summary 字段 | 无直接一手系统先例；SeaEvo 双空间档案（代码+策略层，arXiv:2604.24372，系统优化 +21%）与 LoongFlow plan 字段（Listing 1）提供素材层证据【推断】 | P18 语义层已就位（plan/summary 是档案标准字段）后零成本升级；任务的行为差异主要在策略层而非代码层时 |

### 2. 隐藏结构

- **descriptor 是 MAP-Elites 的全部权力所在，也是全部脆弱性所在**：网格的多样性保证只覆盖"descriptor 张成的空间"——descriptor 退化（LoongFlow 浅层代理）意味着网格在真实行为维度上退化为单池+随机标签，且该退化在任何单点指标上不可见（与 M4-4c、P19 根因 2 同构）。**descriptor 质量必须有独立探针**（格内表型距离 vs 格间表型距离比值），否则 MAP-Elites 是"有网格之名无隔离之实"。
- **evaluator_metric 档的隐藏优势是"零同步成本"**：descriptor 与评估天然同版本——手工/语义 descriptor 需要独立维护与评估环境的版本对齐，评估器升级后 descriptor 可能静默失效；用评估指标本身当维度则不可能脱钩【推断：这是 OpenEvolve"低成本高价值"评价的真实含义】。
- **AlphaEvolve 的"多指标进化反而更好"是本轴与 P2 的桥梁**：多指标既充当 descriptor（P6）又充当多目标前沿（P2）——同一数据两处消费，与 FunSearch signature 的三重复用同族。LLM 进化系统的共同模式：**评估输出是唯一可信的行为信号源，档案结构的一切维度都应优先从评估输出派生，而非独立构造**【推断】。
- 实现陷阱：binning 粒度（每维格数）从未被任何 LLM 进化系统消融——QD 经典文献对格数敏感（粗网格=多样性不足，细网格=格间竞争无意义），LLM 域全部沿用隐含默认【推断】。

### 3. 反直觉结论

**descriptor 不需要"理解"行为，只需要"与评估同源"**——QD 传统认为好的 descriptor 需要领域专家手工设计（handcrafted 档）；OpenEvolve 的实践证明把评估器顺手输出的 metric 直接当维度（甚至包括"代码长度"这类浅层量）反而更可靠，因为它与评估永不脱钩、零维护、零版本漂移。LoongFlow 的退化教训不是"浅层 descriptor 不好"而是"**浅层 descriptor 冒充了行为 descriptor**"——问题在名实不符，不在浅层本身。semantic 档的真正价值因此不是"更深的 descriptor"，而是把网格索引与 P18 的语义层统一，让"假设网格"同时服务检索与治理。

### 4. 与其他模块接口

- **×P18**：semantic 档与档案语义表示共用 plan/假设类别——descriptor 升级依赖 P18 字段先就位。
- **×P19**：descriptor 退化由健康探针暴露（格内/格间距离比、格覆盖率时序）；本轴是 P19 的主要被监控对象之一。
- **×P5**：signature 聚簇是 evaluator_metric 的极端形态（全部测试分数都当维度）。
- **消费 M8**：评估器输出的指标集合决定本轴可选维度；评估器版本变更须触发 descriptor 台账重置。

### 5. 证据空缺

- 三种来源之间无同任务对照；evaluator_metric 档的"好"只有工程评价（低成本高价值）无消融数字。
- binning 粒度（格数/维数）在 LLM 进化域零消融。
- semantic 档（plan 嵌入 descriptor）无系统先例，纯设计外推；SeaEvo 的 +21% 是双空间档案整体的增益，descriptor 维度的独立贡献未分离。

## P7 亲本池字段集（★刚性契约，写死对齐 M2-O11）

### 1. 取值表

| 取值 | 机制展开（怎么工作） | 量化证据（一手数字+来源） | 何时选（前置条件） |
|---|---|---|---|
| 四固定字段（island_id / children_count / rarity / per_instance_best 表） | 类型层写死、不可裁剪：island_id 支撑跨岛均匀/加权岛选择；children_count 支撑"分数×(1+子代数)"类反精英权重；rarity 支撑新颖性加权供亲；per_instance_best 表支撑覆盖比例采样 | 全部四字段有一手先例：LoongFlow Listing 1（Solution dataclass：parent_id/generate_plan/summary/**island_id**/score/sample_cnt/**sample_weight**/generation）【一手】；DGM §C.2（父代选择概率 ∝ 分数×(1+子代数)——children_count 直接先例）【一手】；GEPA per-instance 矩阵="per-instance 最优表"字段的直接物化（GA 卡 1.5）；OpenEvolve Program dataclass（island_id 等）【一手】 | **默认值（四字段全供给，不可裁剪）**。裁掉任一字段=删掉 M1 某类选择策略的表达能力，且裁剪节省的成本≈0（字段是标量/小表） |
| +可选字段 | sample_weight（rarity 的物化先例，LoongFlow 直接持久化采样权重）；score_vector（逐测试分数，P5 signature 的素材）；migrated 标记（P4 迁移防重/谱系） | LoongFlow 迁移副本"保留原 plan/summary/sample_weight"（base_memory.py 一手）——可选字段随迁移事件跨岛流动的先例 | 对应机制启用时追加：sample_weight 随 P8 weighted 骨架；score_vector 随 P5/P2 per-instance 档；migrated 随 P4 ring_migration |

### 2. 隐藏结构

- **字段集是 M4 与 M1 之间的"最少知识契约"**：M1 的选择算法可以任意演进（规则→bandit→RL），但只要四字段在，全部已知供给函数（FunSearch 分层、OpenEvolve 三路、GEPA 覆盖比例、DGM 反精英加权、ShinkaEvolve 新颖性加权）都可表达——**字段集的上位性已被五系统先例枚举验证**。反过来，任何新选择策略若需要四字段之外的数据，即是字段契约的扩展提案，须走契约变更而非私开信道（OpenEvolve 硬编码反例：策略直接长在 ProgramDatabase 里，绕过了任何契约）。
- **children_count 是最反直觉的字段**：它让"被用得越多的亲本权重越高"（DGM §C.2）——表面违反多样性直觉，实质是 stepping stone 信度代理（子代多=该节点已被验证可扩展）。rarity 与 children_count 是一对反向字段（一个奖励少用、一个奖励多用），两者同时供给使 M1 可以在"exploit 谱系深度"与"explore 新鲜度"间调参而无需 M4 改结构。
- **per_instance_best 表是唯一有预算语义的字段**：它的维护成本即 GEPA 的 85–90% 预算税（×P2/P10）——四字段中三个是近零成本标量，一个可能吃掉整个预算。契约写死"字段供给"不等于写死"维护强度"：per-instance 表可以全量维护（GEPA）也可以动态子集维护（GEPA 作者的 future work），M4 侧须把维护档位与字段供给解耦【推断】。
- 实现陷阱：字段的**时效语义**未在契约中显式化——children_count 是累计值还是窗口值？rarity 相对当前代还是全历史？各系统先例不一致【推断】；异步架构下字段读取与写入竞态（迁移中 children_count 变化）会使同一亲本在两次采样中呈现不同字段值（×P12）。

### 3. 反直觉结论

**亲本池契约的最优形态是"过度供给"——供给比当前选择算法所需更多的字段，而不是按需供给**。直觉认为接口应最小化；但本契约的证据基础恰恰是：四个字段各自对应一个**已被消融证明有效**的选择机制（DGM 反精英加权、ShinkaEvolve 新颖性、GEPA 覆盖比例、岛模型分层），字段缺位=该机制在 M1 侧永久不可启用。字段的边际存储成本≈0 而选择机制的边际收益已被独立验证（ShinkaEvolve Fig.9 父代加权消融），过度供给是严格占优策略。真正的约束不在存储而在**语义一致性**：四个字段的时效口径必须统一声明，否则 M1 的策略在跨 run/跨 checkpoint 间不可比（与 M4-7 谱系断裂同根）。

### 4. 与其他模块接口

- **刚性契约写死对齐 M2-O11**：四固定字段不可裁剪；本轴是 M4 对 M2/M1 的最主要供给面。
- **×P20**：供亲资格位是本契约的新增布尔位——被污染探针标记的候选**字段全部在位但供亲位关闭**（F-B4 的存储侧执行点；判定逻辑在 M9）。
- **×P4**：migrated 标记随迁移事件写入；迁移副本的字段继承规则（plan/summary/sample_weight 保留，LoongFlow 先例）是本轴的实现细节。
- **×P13**：谱系四元组 {祖先链, 变异算子与 diff, 上下文配方, 评估环境版本}（F-B13）与四字段并列——缺四元组的候选可留档不供亲，即"谱系完整度"也是供亲资格的前置。
- **消费 M8**：per_instance_best 表的维护强度由 M8 噪声底与预算（M3）联立决定（F-B9）。

### 5. 证据空缺

- 四字段的**联合充分性**未经验证——五系统先例各自只用了子集，无任何系统同时供给四字段；"字段集足以表达一切已知供给函数"是枚举归纳【推断】。
- 字段时效语义（窗口 vs 累计）无标准，跨系统不可比。
- P20 供亲位与 P7 契约的合并（布尔位 vs 独立表）是接口待定项，无任何实现先例（供亲位分离本身是 B 组盲区补轴 P20，全领域无系统实现过）。
