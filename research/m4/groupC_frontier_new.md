## (1) 前沿系统档案结构精读（一手锚点）

- **AlphaEvolve**（arXiv:2506.13131，DeepMind 白皮书，2025-06）：MAP-Elites 启发的 program database + Gemini Flash/Pro 双档集成 + 自动评估器级联；从 FunSearch 的单函数扩展到整个代码库。关键遗产：档案首次承载"跨 run 长期演化的生产级 artifact"（数据中心调度、芯片设计、LLM 训练 kernel）。
- **ShinkaEvolve**（arXiv:2509.19349，Sakana AI，2025-09）：固定容量档案组织为岛屿子种群（岛屿并行+迁移，岛屿最优个体免受迁移）；父代采样 = 幂律/性能×新颖性加权（新颖性=后代少者优先）；**新颖性拒绝采样**——嵌入可变代码片段、对档案算相似度，超阈值再问第二个 LLM 判"实质新颖性"；UCB1 bandit 选 LLM 集成；**meta-notepad** 定期从成功个体提炼高层策略附进变异 prompt。圆打包任务 <150 次评估即超 AlphaEvolve 解。
- **GEPA**（arXiv:2507.19457，2025-07）：档案 = **per-instance Pareto 前沿**（每个任务实例上的最优候选集合），候选选择按"出现在 Pareto 前沿的频率"随机采样；反思式变异 + System-Aware Merge。档案语义从"MAP-Elites 行为格"变成"实例级非支配集"。
- **EvolveNet**（arXiv:2608.04968，2026-08-05）：跨组织**联邦式档案**。共享 harness 广播 → K 个数据本地 client 各自进化 → 只回传 program delta + 行为证据 → server 做 scope-typed（全局/域条件化）证据门控合并 → 重分发。量化：BIRD held-out 70.7% vs 等总预算集中式 population 67.3%（配对 14 胜 9 负）vs 等串行深度集中式 68.7%（无门控链式直接崩溃回滚）；DS-1000 合并 harness 比最强单 client 高 9.0 分；五 benchmark 全部显著（McNemar/Wilcoxon，Holm 校正后均成立）；换整套模型栈（deepseek-v4-flash→MiMo-V2.5）定性行为复现。
- **RelayEvolve**（arXiv:2608.05651，2026-02/08）：档案成为**跨模型相位移交的对象**。维护去重候选池 + 在线 relay bank（|S|≤k，top-r 质量 + 多样性覆盖的单调子模目标 F）；Relay Gain = bank 的边际改进，同时驱动 bandit 调度、handoff 时机与种子集选择（贪心子模 + 局部交换，(1−1/e) 保证）。4 benchmark × 3 预算中 11/12 设置均值最高。一手规律：进展强前置、早期轨迹信号有用但嘈杂、便宜模型前 20 代捕获强模型 0.82–1.01× 的进展。
- **EvoDiverse**（arXiv:2606.10587，2026-06；ICML 2026）：**并行回火（parallel tempering）档案**——冷/热多温度池，各自按 Boltzmann 权重选择，池间 Metropolis-Hastings 交换。一手发现：标准 LLM 进化在多领域出现系统性**多样性坍缩**；EvoDiverse 同预算下质量+多样性双升，同 prompt 消融（仅 β 不同）仍 +12%/+19% Top-10 AUC（JNK3/GSK3β），证明收益来自 PT 机制而非 prompt。
- **IDEAgent**（arXiv:2607.22375，2026-07）：科研 ideation 的 agentic QD。档案**四存储结构**：活跃档案 A（已接受）、修复队列 Q（near-miss 暂存）、历史档案 H（被替换/挤出者的签名）、**拒绝档案 R 不存个体而存聚合的失败模式**供生成时显式回避；谱系 ℓ_I 为单位计预算（一次发现预算=一条谱系）。放弃预定义行为轴，直接从"问题+因果机制"判多样性。
- **SeaEvo**（arXiv:2604.24372，2026-04）：档案条目 = (程序, 适应度, **自然语言策略描述 + 嵌入**)，双空间（代码+策略）档案；SLN 每 Δ 代总结"有效/饱和/未探索"策略家族指导变异。系统优化任务上相对底层 backbone 平均 +21%。
- **FunSearch 后续谱系**（一手引用自查）：OpenEvolve（开源复现）、CodeEvolve（岛屿 GA + LLM 算子）、PACEvolve（层级上下文+动量回溯+跨岛采样）、AdaEvolve（层级自适应优化）、DeltaEvolve、DeepEvolve、GigaEvo、T-Discover（2026）。
- **2026 QD×LLM 新工作**：分布式 QD + Red Queen（arXiv:2605.27130：跨节点 gossip 传递异构 LLM 的 champion 作为对手，MAP-Elites 内实例化 Red Queen 压力，hall-of-fame 档案跨节点共享）；KernelFoundry（MAP-Elites + meta-prompt 进化，KernelBench SYCL 2.3× 平均加速）；QD 用于 LLM 安全红队（ICLR 2026 AIWILD，6×6×6 MAP-Elites，语义基因组）。

## (2) 逐项新发现卡片

### 卡片 1：档案的联邦化与跨 run 合并协议——档案不再是单 run 私有状态（EvolveNet）
- **发现**：多个部署点各自持有本地进化轨迹（本地档案），跨边界流动的不是数据而是 program delta + 行为证据；server 端合并本身就是档案操作（diff→机制分解→scope 分类→条件化组合→逐 item 准入门→失败回滚）。
- **来源+日期**：arXiv:2608.04968，2026-08-05。
- **量化证据**：如上精读条目（70.7 vs 67.3/68.7；+9.0；全显著）。
- **为何在既有轴系之外**：经典档案轴隐含"单一进化主体、单一进程"。这里是档案的**分布拓扑与合并语义**——档案合并是非算术的（程序不可平均），2023 前 QD 文献无此问题。

### 卡片 2：档案作为跨相位移交对象——handoff 集本身是优化目标（RelayEvolve）
- **发现**：档案不只是"存历史"，而是要被**压缩成一个可移交的子集**传给下一阶段（更强模型）。什么样的档案子集值得移交被显式建模为单调子模目标（top-r 质量+多样性覆盖），其边际增益（Relay Gain）反过来当调度奖励。call 级 bandit 被证明近视。
- **来源+日期**：arXiv:2608.05651，2026-02-15。
- **量化证据**：11/12 设置均值最高；前 20 代便宜/强模型进展比 0.82–1.01×。
- **为何在既有轴系之外**：既有"父代采样"轴管从档案读什么；这里档案**整体被打包、估值、移交**——档案的生命周期与估值维度。

### 卡片 3：档案作为可学习的语义对象——双空间档案与策略层（SeaEvo / ShinkaEvolve meta-notepad）
- **发现**：档案条目从 (program, fitness) 扩展为 (program, fitness, 策略描述, 嵌入)；档案上跑聚类与"景观导航"总结，生成"哪些策略家族有效/饱和/未探索"的持久元知识。档案成为**被 LLM 反复读取并反写的语义地图**。
- **来源+日期**：arXiv:2604.24372，2026-04-27；ShinkaEvolve meta-notepad，2025-09。
- **量化证据**：系统优化任务平均 +21%；Prism 上策略档案使 run 跳出局部平台（26–30→42.94）。
- **为何在既有轴系之外**：这是档案**内容表示**的新维度（语义/策略层 vs 纯 artifact 层），2023 前 MAP-Elites 的行为描述子是人工低维向量，不存在"LLM 生成+LLM 消费的档案元表示"。

### 卡片 4：档案的记忆分层——活跃/暂存/历史/失败模式的四存储结构（IDEAgent）
- **发现**：档案拆成四个不同语义的存储：活跃集 A、修复暂存 Q、历史签名 H（被替换者的指纹，防止重复计入发现预算）、以及**失败模式聚合库 R**——不存失败个体而存聚合模式，用于生成时显式回避。谱系（lineage）成为预算计量单位。
- **来源+日期**：arXiv:2607.22375，2026-07-24。
- **量化证据**：HF daily 摘要指出其评估重依赖 LLM judge（可信度警示）；具体增益数字【未复核】。
- **为何在既有轴系之外**：既有档案轴假定单一容器+准入规则；这里是**多存储分工 + 阴性知识的一等表示**（失败聚合入库）。经典 QD 的 rejection 是丢弃，不是建档。

### 卡片 5：档案的温度分层——parallel tempering 池间 MH 交换（EvoDiverse）
- **发现**：多池不是岛屿（地理隔离+偶发迁移）而是**温度梯**（选择压力 β 梯），池间交换用 Metropolis-Hastings 准则保证近似采样语义。一手发现：标准 LLM 进化在分子/方程/算法发现上系统性多样性坍缩。
- **来源+日期**：arXiv:2606.10587，2026-06-09（ICML 2026）。
- **量化证据**：同 prompt 消融（只差 β）仍 +12%/+19% Top-10 AUC；方程发现误差曲线一致更低。
- **为何在既有轴系之外**：岛屿模型是旧取值，但"**温度作为档案分层维度 + 有原则（MH）的池间交换**"在 LLM 进化语境是新的组织原则——它把档案语义从"优化"改为"从 Boltzmann 分布采样"。【推断】可被收编为"档案间交互协议"轴的一个新取值而非独立轴。

### 卡片 6：档案的分布式对抗共享——跨节点 hall-of-fame 作为对手库（分布式 Red Queen QD）
- **发现**：MAP-Elites 档案跨节点 gossip 交换的不是解而是**对手**（champion 程序），在档案内实例化 Red Queen 军备竞赛；异构 LLM（Codex/Claude/Gemini/Qwen）互为多样性算子。
- **来源+日期**：arXiv:2605.27130，2026（Core War testbed）。
- **量化证据**：为 workshop/扩展摘要级证据【未复核具体数字】。
- **为何在既有轴系之外**：档案内容的**对抗性复用**（档案条目作为其他搜索的压力源）+ 跨主体档案同步协议。与卡片 1 同属"档案的分布与合并"大轴的另一取值。

### 卡片 7：档案经济学——存储/检索/移交成本进入设计（RelayEvolve / IDEAgent / ShinkaEvolve）
- **发现**：三处成本考量一手可见：(a) relay bank 限定 |S|≤k 因为移交带宽有限；(b) IDEAgent 明确"不给 Ideator 喂全部历史全文，只给紧凑表示，为了计算效率"；(c) ShinkaEvolve 固定容量 + 嵌入相似度去重。档案大小的约束从"内存"变为"prompt token / 注意力预算"。
- **来源+日期**：arXiv:2608.05651、2607.22375、2509.19349。
- **量化证据**：无独立基准【推断性强】。
- **为何在既有轴系之外**：2023 前档案成本=计算内存；LLM 时代档案成本=**上下文窗口与 API 美元**。是新轴候选但证据分散。

### 卡片 8：test-time 档案——评估内构建、无标签代理信号准入（TTHE）
- **发现**：档案在评估期间从零构建，gold 对 proposer/judge 隐藏，候选只能靠当前无标签 batch 的执行代理信号准入。
- **来源+日期**：arXiv:2607.08124，2026-07-09（M2 扫描卡片 7 已立，此处从 M4 视角重述）。
- **量化证据**：【未复核】。
- **为何在既有轴系之外**：档案的**运行时机与证据制度**（offline 有标签 vs test-time 无标签）。M4 侧意义：档案生命周期可以短到一次评估。

## (3) 结论

### 候选新轴清单（按证据强度排序）

1. **档案的分布与合并轴**。定义：档案存在于单进程还是跨主体/跨 run 分布；合并协议是什么。候选取值：单主体集中式 → 多 run 事后合并 → 联邦式 delta+证据门控合并（EvolveNet）→ 对抗式 champion 交换（Red Queen QD）。证据锚点：EvolveNet 70.7 vs 67.3（等预算集中式）且合并协议消融（Delegation/GLOBAL-only/select-best）各自证明贡献。**建议收编，最强候选**。理由：一手量化强、2023 前无此问题、直接决定 M4 模块接口。
2. **档案移交/估值轴**。定义：档案（或其子集）作为跨相位、跨模型档位移交对象时如何估值与压缩。候选取值：无移交（单模型单相位）→ 固定切换 → 子模目标估值+自适应 handoff（Relay Gain）。证据锚点：RelayEvolve 11/12 设置最优；call 级 bandit 近视的一手对照。**建议收编**。理由：是"档案作为状态耦合资产"的独有属性，不能归入父代采样轴。
3. **档案内容表示轴**。定义：档案条目除了 artifact+fitness 还持久化什么。候选取值：纯 artifact → +行为描述子（旧）→ +NL 策略描述/嵌入（SeaEvo）→ +失败模式聚合（IDEAgent R）→ +meta-notepad 提炼（ShinkaEvolve）。证据锚点：SeaEvo +21%；IDEAgent 四存储。**建议收编**。理由：LLM 使"档案存语义层"零成本化，2023 前不存在。
4. **档案记忆分层/多存储轴**。定义：档案是否拆分为语义不同的多存储（活跃/暂存/历史/阴性库）。候选取值：单容器 → A/Q/H/R 四存储（IDEAgent）→ hall-of-fame 对抗库（Red Queen）。证据锚点：IDEAgent 一手设计；但增益量化弱。**建议暂收为轴 3 的子结构或标注观察项**。理由：目前单点证据，等复现。
5. **档案经济学轴**。定义：档案大小/检索成本按 token 与 API 美元核算的设计。候选取值：无成本意识 → 固定容量+嵌入去重 → 紧凑移交集（k 受限）→ 失败聚合代替全文存储。证据锚点：三系统分散证据，无专文。**建议作为横切约束记录而非独立轴**，除非后续出现专文基准。
6. **档案证据制度轴**。定义：档案在什么证据体制下准入（有标签离线 vs 无标签 test-time 代理）。候选取值：offline 有标签 → test-time 代理信号（TTHE）。证据锚点：TTHE 单点。**建议与 M2 治理轴对齐后作为 M4 准入轴的一个取值**，不单独立轴。

### 看似新、实则旧轴取值的东西
- **ShinkaEvolve 岛屿迁移、EvoDiverse 温度池、CodeEvolve 岛屿 GA**：组织结构是"岛屿模型"旧取值；EvoDiverse 的 MH 交换与采样语义是唯一溢出部分（见卡片 5，建议并入"档案间交互协议"而非独立轴）。
- **GEPA 的 per-instance Pareto 档案**：是"档案结构=Pareto 前沿"旧取值在实例粒度上的具体化；"按前沿出现频率采样父代"是父代采样轴新取值。不构成新轴。
- **ShinkaEvolve 的 UCB1 bandit 选 LLM、新颖性拒绝采样**：分别是选择策略与准入规则轴上的新取值（M2 已判定同类）。
- **KernelFoundry 等"MAP-Elites 用在 kernel/提示词"**：旧结构在新域的实例繁荣，只增加证据密度。

### 阴性发现（以为存在但 2026 不存在）
1. **跨 run 档案合并的通用协议/标准格式不存在**。EvolveNet 是唯一一手系统，且其合并是 LLM-merger + 任务特定证据门控，无可移植的"档案合并接口规范"；多次搜索 "cross-run archive merging" 无任何专文命中。对照：M2 的"算子共享生态不存在"。
2. **档案经济学无专文基准**。没有任何论文以"档案存储/检索的 token 成本"为主变量做消融；成本论述全部散落在系统论文的实现细节里。
3. **"档案作为可微/可训练对象"不存在**。SeaEvo 把档案语义化、RelayEvolve 把档案子集化，但没有任何工作把档案管理策略本身做成被 RL/梯度训练的对象（对照 M2 的 Harness-R1 之于算子）。【推断】这是 2027 的明显空位。
4. **EvoDiverse 的 arXiv 号易误传**：检索确认 2606.10587 确为 EvoDiverse（《Towards Diverse Scientific Hypothesis Search with Large Language Models》），但其 ICML 2026 页面摘要以"Unlocking Zero-Shot Geospatial Reasoning via Indirect Rewards"标题混排出现——引用时须以 arXiv 页面为准。
5. **test-time 档案无第二家**。TTHE 之外未找到任何"评估内建档案"的复现或后续，单点证据风险高。
