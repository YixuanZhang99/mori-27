# 任务一：七个经典分歧裁决

## 分歧 1：档案拓扑——grid×islands 组合 vs 树/单池（P1）

### 两方最强论据

**组合拓扑方（grid×islands）**：OpenEvolve `ProgramDatabase` = MAP-Elites×islands×archive 三结构合一（database.py 一手），LoongFlow 收敛到同形态——三家独立实现的工程收敛是档案侧最强的正面证据形态；DGM 去 archive 消融显著退化（arXiv:2505.22954 §4.3）证明"有档案 vs 无档案"是一阶问题，网格×岛是"档案存在之后"最强的二阶形态。

**树/单池方**：DGM 树（全体存活节点即前沿）有同论文消融背书，且在"谱系天然即档案"语义上最省；Simple Baselines 的 SCS 无档案极端在小验证集上 P(Shinka>IID RS)=0.49（arXiv:2602.16805）——档案拓扑的全部精妙在噪声底下不可证真；AIDE² 单链表达达 RSI L1（weco.ai 博客级，方向被 DGM 消融独立佐证）；树形态的"无驱逐"免除 M4-3 整类失效，组合形态必须自己负担容量治理。

### 裁决规则

- **裁决变量**：评估噪声底是否已知且足够低（P15 前置）× 是否需要跨代对照/回退能力。
- **裁决规则**：默认 `grid×islands`（表达力上限 + 双机制多样性承载）；但任何非单链拓扑是**条件合法**——必须通过 P15 退化自检：与自身结构的单链/SCS 投影常驻对照，增量须超 M8 噪声底。树形态作为"免驱逐"特例保留为合法取值（驱逐需求由 P10 裁决，见分歧 4），单池仅在 K=1 退化配置下合法。
- **前置条件**：M8 噪声底测量就位；无噪声底时组合拓扑的收益不可判定（SB 0.49）。
- **默认值**：`grid×islands` + P15 resident 自检常开。

### 落成方式

- **配置项**：`archive_topology ∈ {single_pool, islands(K), grid, matrix, tree, grid×islands}`，默认 `grid×islands`。
- **硬编码**：退化投影对照不可从构建中移除（P15）；拓扑切换=谱系事件入 X1。

## 分歧 2：前沿粒度——Pareto-per-instance vs cell_elite vs 单链（P2）

### 两方最强论据

**Pareto-per-instance 方（GEPA）**：per-instance Pareto 消融 +6.4%、样本效率 35×（arXiv:2507.19457，ICLR 2026 Oral）——前沿粒度是全部档案轴中单消融数字最强的一条；逐实例最优表天然防"平均数掩盖专长"。

**粗粒度方（cell_elite/单链）**：GEPA 自己承认 ~85–90% rollout 花在维护 per-instance 验证表上，作者将"动态选择验证子集"列为 future work——前沿表示精度与维护成本成正比、与选择收益不成正比（M4-5 教科书形态）；噪声实例上的"实例最优"大概率是 lucky sample（M4-8 共谋）；单链无档案在噪声下打平复杂系统（SB P=0.49）。

### 裁决规则

- **裁决变量**：是否存在逐实例评估结构 × 前沿维护成本占评估预算的比例。
- **裁决规则**：逐实例评估场景默认 `pareto_per_instance`，否则 `cell_elite`；`best_so_far` 禁止作默认（M4-6，E7 公理化）。任何 per-instance 粒度必须带**粒度×预算联立声明**（F-B9→E6）：全量维护预算占比超阈值自动降粒度（动态子集/分层抽样）；粒度升级必须与评估严格度（每实例重复次数）匹配，噪声实例席位带置信度标记、低置信不供亲（E11 联动）。
- **前置条件**：M8 提供 per-instance 噪声分解；预算占比阈值进配置（占位符，见诚实边界 1）。
- **默认值**：逐实例场景 `pareto_per_instance` + 预算上限声明；否则 `cell_elite`。

### 落成方式

- **配置项**：`frontier_definition ∈ {cell_elite, pareto_per_instance, tree_leaves}`（best_so_far/none 不在合法取值集）；`frontier_budget_cap` 为一等字段。
- **协议**：前沿维护成本按代记账入 X1（与 M3 预算对账），超限自动降粒度事件入谱系。

## 分歧 3：岛数 K 与迁移参数——惯例继承 vs 待证默认（P3×P4）

### 两方最强论据

**惯例方**：岛数谱系 10→5→3→2（FunSearch→OpenEvolve→LoongFlow→ShinkaEvolve 四系统一手配置）；OpenEvolve 迁移 rate=0.1/interval=50、LoongFlow rate=0.2/interval=10 双点收敛；FunSearch 10 岛 + 4h 重置是 15 代不退化的生产配置。

**待证方**：岛数递减是时间线而非剂量-反应曲线——混杂部署规模、任务转向、迁移机制成熟、新颖性闸替代四个共变因子（part1-P3 证据空缺诚实展开）；**无任何一手同预算消融把 K 作为自变量扫描过**；动态繁殖（stagnation_threshold=100）零消融；FunSearch 4h 固定周期与演化阶段无关，被 PDE-SHARP 等生态原样继承——失效超参被生态继承（M4-4）；稠密通信拓扑加速塌缩（arXiv:2604.18005）说明迁移率本身是塌缩调速器。

### 裁决规则

- **裁决变量**：跨岛表型距离时序（P19 探针）是否在位。
- **裁决规则**：K=5 默认值的法律地位明确标注为"惯例中位数"而非"被验证最优点"（与 M2 边界声明 4 同型：只记账不定参）；迁移默认 `ring_migration(rate=0.1, interval=10~50)`；**固定周期迁移/重置为待证默认**——P19 探针就位后，跨岛距离单调下降即触发迁移率下调/岛重启（E4），治理依据从墙上时钟切换到探针读数；驱逐式的 FunSearch reset（杀半岛）让位于迁移+软重启（dim06 §3.7"迁移替代重置"）。
- **前置条件**：P19 跨岛距离探针实现（度量选择本身无先例，见诚实边界 1）；无探针时退回固定周期保守档并标注待证。
- **默认值**：K=5 + ring(0.1, 10~50) + 探针反馈治理就绪后切阶段感知。

### 落成方式

- **配置项**：`island_count`（默认 5）、`migration = {rate, interval, trigger ∈ {periodic, probe_gated}}`，默认 periodic、探针就位后切 probe_gated。
- **协议**：K/迁移参数变更与探针读数快照同时入 X1（治理动作可归因）。

## 分歧 4：驱逐裁决——按点估计排序 vs CI 下界 + 软删除（P10×P20）

### 两方最强论据

**点估计方**：OpenEvolve `_enforce_population_limit`（pop=1000/archive=100）按当前分数淘汰最差——实现零成本、无额外评估开销；cell_competition 同格替换天然限容，MAP-Elites 三十年惯例。

**CI+软删除方**：Justesen 2019 一手测量——朴素基线档案质量随时间退化、矫正重评后"空格"（档案里相当比例精英经不起重评）；UQD（arXiv:2302.00463）Archive-Sampling 显著优于固定采样——"不重评"是被证伪的默认；CMA-MAE archive threshold dynamics：按点估计的瞬间替换杀 stepping stone 致早熟；AIDE `is_buggy` 永久误杀（驱逐误杀生产级案例）；驱逐决策在噪声底之下是随机的却产生不可逆后果（M4-8 后半）。

### 裁决规则

- **裁决变量**：驱逐双方的分数差是否大于联合噪声底（M8 A11 供给）。
- **裁决规则**：**噪声底下不裁决**（F-B16→E12）：分数差小于联合噪声底的驱逐/保留决策视为不可裁决，触发重评或随机化，禁止按点估计静默执行；一切驱逐走**软删除+深度缓冲**（标记、留谱系、可恢复路径，硬删除默认禁止，E5）；交付位晋升须 CI 下界高于被替代者点估计（保守晋升，E11）；档案定期重评预算为一等配置，"一次评估终身有效"为禁止配置。
- **前置条件**：M8 ReliabilityMeta（强制 CI95）就位；驱逐操作的消费方是 P20 资格位而非物理删除。
- **默认值**：`population_limit + cell_competition` 限容 + 软删除执行 + CI 下界裁决 + 重评预算。

### 落成方式

- **硬编码**：驱逐记录 {理由, 双方 CI, 可恢复路径} 三字段强制；`hard_delete` API 不存在（只有 deprecate/quarantine）。
- **配置项**：`eviction_rule ∈ {point_estimate, ci_lower_bound}`，默认 ci_lower_bound（点估计档仅在本代重评预算耗尽时降级使用并报警）。

## 分歧 5：亲本三路采样配比——固定 0.7/0.2 vs 自适应/探针驱动（P8）

### 两方最强论据

**固定配比方**：OpenEvolve 0.7/0.2 三路 + double selection 是生产验证配置；FunSearch 温度退火（T0=0.1, period=30000）同样是固定日程；VRP 纯贪心 3 代塌缩（arXiv:2604.07872）证明 exploit 比例必须有硬下限约束之外的结构性对冲。

**自适应方**：ShinkaEvolve 父代消融三档排序 weighted > hill climbing > random——供给函数是性能决定变量；塌缩的开关在档案侧（M4-1），固定配比无法响应供应侧塌缩；供给熵/浓度指标（F-B1/F-B6）存在的意义就是驱动供给函数切换（F-B2 要求可热替换）。

### 裁决规则

- **裁决变量**：P19 供给熵探针是否在位 × 切换增量是否超噪声底。
- **裁决规则**：默认固定三路（0.7/0.2 为工程惯例值、明确标注未消融）+ double selection；配比是**结构分区的参数而非公式**——选择公式/权重归 M1（刚性边界），M4 只供给三路分区与注入点；探针反馈治理（供给熵超阈→切供给函数）为一等升级路径，切换必须按 C10 同型规则跑赢退化对照。与 M2 分歧 2（π_op 规则表 vs bandit）同构裁决：先结构后自适应。
- **前置条件**：供给函数可热替换（E2）；策略注入点一等接口（OpenEvolve 硬编码为反例）。
- **默认值**：three_way(0.7/0.2) + double selection，探针驱动的供给切换默认关。

### 落成方式

- **配置项**：`parent_sampling = {scheme: three_way, ratios: [0.7, 0.2, 0.1], adaptive: false}`。
- **协议**：每代供给函数版本+配比快照入 X1；M1 注入的策略只消费 M4 暴露字段（P7 契约）。

## 分歧 6：跨 run 档案合并——自由合并扩充亲本池 vs 重标定门控（P16）

### 两方最强论据

**合并门控方**：EvolveNet（arXiv:2608.04968）BIRD held-out 70.7% vs 等总预算集中式 67.3%（配对 14 胜 9 负）——分布化的价值被证明住在合并协议里（scope-typed + 证据门控），无门控链式版本直接崩溃回滚；不同评估版本的分数不可直接比较（F-B14，与 E 系 A16 锚点呼应）。

**自由合并方**：免费扩充亲本池的诱惑真实存在；且生态现状是"取各 run 最优"而非合并——连事故报告都没有（GB 不确定性 3：作为结构风险而非已发事故记录）；重标定档（共享锚点集）零实现先例，锚点集大小/重评预算/漂移容忍度全部无标定（part3-P16 证据空缺）。

### 裁决规则

- **裁决变量**：合并双方是否可过共享锚点集重标定 × 驱逐可证伪性是否就位（E5）。
- **裁决规则**：默认单主体集中式；跨 run 合并的双前置硬门——(a) 共享锚点集重标定（分数跨 run 可比性由锚点建立而非假设），(b) 目标档案驱逐可证伪（软删除就位，合入错误可回滚）；合并档案每候选标注来源 run id、跨 run 谱系边标"异源"（新增谱系类型）；被污染 run 的"跨 run 召回"（与 F-B3 联动）登记为设计外推，只允许以 quarantine 整批隔离的形态实现。
- **前置条件**：M8 锚点机制；X1 支持异源谱系边。
- **默认值**：单主体集中式；合并档注册、默认关。

### 落成方式

- **配置项**：`distribution ∈ {centralized, cross_run_gated, federated_delta}`，默认 centralized。
- **协议**：合并事件 {来源 run id, 锚点集版本, 逐 item 准入门结果} 进 X1；逐 item 准入判定归 M9（刚性边界）。

## 分歧 7：失败候选地位——硬删/discard vs buggy_leaf 保留 vs 阴性聚合库（P11×P18）

### 两方最强论据

**保留方**：AIDE `is_buggy` LLM 自判永久误杀（M2-O12/M4-3 双重记录在案）——被误杀节点无后续数据可平反；失败候选是 debug 算子的天然亲本（M2-O12 消费方）；谱系留痕是事后归因的唯一材料。

**硬删/聚合方**：FunSearch 不计分即不入库是生产默认且未报告过因此失效；IDEAgent R 阴性聚合库（不存个体存聚合失败模式）主张"失败的知识价值在模式不在个体"；保留失败个体膨胀档案、稀释采样（M4-3）；IDEAgent 增益量化【未复核】且评估重依赖 LLM judge（可信度警示）——阴性知识档的全部证据是弱证据。

### 裁决规则

- **裁决变量**：失败判定的来源（环境事实 vs LLM 自判）× 失败模式的可聚合性。
- **裁决规则**：默认 `buggy_leaf`（标记保留、不参选、可复活、留谱系）；**失败判定只能来自环境事实**（compile/run 失败），LLM 判断只做优先级排序、不做入库硬过滤——与 I-LLM 及 M2-C11 逐字对齐；`discard` 仅对环境事实失败且超深度缓冲上限的候选合法；阴性聚合库注册为 P18 内容表示的取值（聚合规则归 M5，M4 只到存储结构），证据级别降级标注、默认关。
- **前置条件**：P10 软删除通道就位（buggy_leaf 是其特例）；M2-O12 debug 消费接口。
- **默认值**：buggy_leaf；阴性聚合库默认关。

### 落成方式

- **硬编码**：候选 schema 的 `failure_provenance ∈ {env_fact, llm_judgment}` 字段强制；llm_judgment 来源的失败标记不得触发物理排除。
- **配置项**：`failure_policy ∈ {discard, artifacts_only, buggy_leaf, negative_aggregate}`，默认 buggy_leaf。

# 任务二：失效模式 → 正式公理集（E 系列）

> Group B 的 16 条候选公理（F-B1～F-B16）裁决为 **12 条 M4 定稿公理 E1–E12**。合并规则：同根因同物化点者合并（F-B1+F-B6→E1 供给端双指标；F-B11+F-B12→E7 多峰与回退是同一"可恢复性"轴的两面；F-B13+F-B14→E8 谱系完整性与跨 run 重标定同为 provenance 治理）。降级：E4/E9 降 SHOULD（岛参数零消融、易实例主导定量测量缺位）。编号风格对齐 M5 A 系 / M8M9 B 系 / M2 C 系（陈述 | 来源失效 | 证据锚点 | 强制级别 | 违反检测）。

# 任务三：四共同根因 × 四条不变量 + I-披露候选——跨模块对账

## Group B（M4 侧）四共同根因

1. **幸存者偏差制度化**：精英保留/加权供亲把最 lucky（噪声高分）、最假（hacked）、最窄（塌缩后模式）集中到亲本池头部——M4-1/M4-2/M4-8 同机制三种污染（→ E10/E11/E1）。
2. **档案健康不可从内部观测**：塌缩/岛间趋同/易实例主导/噪声滞留全部在单点 fitness 上隐形，二阶指标在四系统中全部缺失（→ P19、E1/E4/E6/E11）。
3. **不可逆操作跑在延迟证据前面**：驱逐误杀、单峰覆盖、谱系缺省是"便宜且不可逆的治理动作"先于"昂贵且延迟的验证动作"执行（→ E5/E7/E8/E12）。
4. **M4 是 O 系与 E 系失效的汇流放大层**：档案不产生新失效，但决定上游失效是孤立事件还是种群级事故（→ 模块定位公理：限制传播半径）。

## M4 是否贡献新候选不变量：是——**I-可逆（不可逆操作滞后于证据成熟度）**【候选，待框架级确认】

**陈述（建议稿）【推断】**：框架内任何不可逆或高恢复成本的状态变更操作（驱逐、覆盖、合并、删除、硬过滤），其执行门槛不得低于支撑证据的成熟度——证据未成熟（CI 未收敛、重评未完成、审计未跑）时，操作必须降级为可逆形态（软删除/quarantine/标记）或延迟执行；操作的不可逆性档位与所消费证据的 CI/重评状态在类型层绑定。

**框架级普适性论证**（上收判据 = 跨模块投影 + 各自一手失效证据）：

1. **M9 侧已物化一半**：Receipt 失效引擎（三绑 + 失效条件表）+ B11"软证据作废、硬证据永存"正是"证据陈旧 ⇒ 裁决失效"的制度化——这是同一原则在**裁决层**的投影，有一手证据（selective erasure 后 71.7% vs 69.9%）。
2. **M4 侧独立一手证据链**：AIDE is_buggy 永久误杀（LLM 判断做不可逆硬过滤）、Justesen 2019 重评后空格（按不成熟证据做不可逆驱逐）、CMA-MAE threshold dynamics（瞬间替换杀 stepping stone）——三个独立来源证明该原则在**存储层**同样成立，且失效形态各异（过滤/驱逐/替换）。
3. **M2 侧投影**：C11"失败判定只来自环境事实、LLM 判断不做准入硬过滤（保留复活通道）"是该原则在算子治理层的投影——"保留复活通道"就是"降级为可逆形态"的 M2 措辞。
