# M7 immutable Git artifacts and public evaluation reuse

The explicit schema-2 `git_artifact` executor publishes construction results as immutable Git commits before evaluation. It uses exact base blobs and a separate index, stores the commit body and publication plan before publishing the commit/ref, and validates the original journal plus artifact bytes during reuse. Caller worktree/index, filters and hooks do not participate. Without a supplied base repository it creates a managed empty artifact repository; it does not snapshot the caller directory.

Native domains can evaluate Git-published text. Command domains reuse the existing WorktreeCommandExecutor and original process-identity protocol with the artifact commit as its base. Allocated EvalRequest values, including resume_from, are unchanged. Evaluation scratch and log commits remain separate from the original construction artifact. The command supervisor supplies the minimum wallclock charge, including governed control reconciliation.

New tests include actual Git/protected-path checks, same-artifact reuse across dev/admission/final, independent control repositories, pause/resume, no-call recorded replay, and actual SIGKILL at publication-plan/commit and public provider/worker/outcome boundaries. External fsynced provider/worker counters verify no replacement generation or duplicate command execution. Tests reproduced and corrected canonical path aliases, workspace-inside-base configuration, file/directory collisions, producer wallclock underreporting, and the control auditor's legacy-only execution-type check.

The initial broad regression passed 486 new and historical construction/worktree/governance/recovery tests. A subsequent outside-source case exposed the control audit omission while the first full run was active; its passing 2,237-test run is retained only as pre-fix evidence. The permanent control case and focused audit/lifecycle regression then passed 55 tests. The final frozen-source run passed 2,238 Linux tests, 76 tooling tests, 11 axioms, all examples, build and import verification in 308.772 seconds. The refreshed wheel passed the isolated outside-checkout example. Exact source and evidence hashes are recorded in summary.json.

The standalone installed example constructs two original artifacts, evaluates them five times across the configured splits, pauses/resumes, independently reads Git blob bytes and SHA-256 digests, and replays with explosive model/domain adapters. It reports synthetic token usage and offline scores explicitly. No external provider calls or live campaign ledger changes were made.

This completes only the locally verified scope of Task 4; same-commit hosted evidence for this increment is still pending. V9 external currency integration, whole-branch independent review and v74 acceptance remain Tasks 5–6. Full configured concurrency, Mac hardware validation, B1–B5 and whole-framework release acceptance remain open. Native execution is trusted in-process; Git publication itself is not an OS sandbox. Bases containing symlinks/submodules/special entries are explicitly rejected, and only one artifact file is supported. Process-crash evidence does not prove recovery from lost disk writes or whole-machine power loss.
