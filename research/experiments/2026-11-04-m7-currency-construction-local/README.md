# M7 configured construction with protected external currency

The explicit `composed-v9-m7-governed-external` path binds construction configuration, all role definitions and main/control artifact backends into the original currency bridge preparation. Candidate construction and repair retain a single physical operator intent, original continuous provider ordinals, finite call caps and protected future controls. Legacy v8 records retain their meaning.

Public tests use temporary fixture ledgers and real loopback HTTP. They cover native/Git construction, command evaluation against the original artifact commit, one-node build plus repair, known-prefix/unknown-repair reserve retention, charged frozen-hypothesis rejection, cap exhaustion, pause/resume, no-call/no-ledger-write recorded replay, and actual SIGKILL after provider completion, construction outcome, materialization and Git publication. Independent audit tests first reproduced acceptance of self-consistent substituted role instructions, projection/initial hypothesis and artifact output; the corrected audit compares original paid prompts/responses and the frozen construction contract.

The final frozen-source check passed 2,257 Linux tests, 76 tooling tests, 11 axioms, examples/build/import in 330.710 seconds, with unchanged source hashes and exit 0. A new isolated installation outside the checkout passed both the legacy v8 example (4 loopback requests, 152 synthetic micro-CNY) and the v9 construction example (4 artifacts, 8 loopback requests, 304 synthetic micro-CNY), each with no new requests or ledger events on replay.
