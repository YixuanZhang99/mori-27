The public Framework entry accepts an explicit schema-2 execution specification. Built-in draft/reflective/crossover operators supply pure recipes; the selected constructor applies role instructions, projected context and frozen/free hypothesis rules inside the existing measured candidate-production operation. A persisted immutable artifact is reused for evaluation, resumed runs and recorded replay.

The new public tests cover role-directed generation, excluded-context echo policies, feedback retained across policy checkpoints, static instruction preservation, free hypothesis attribution, frozen mismatch with measured cost and no evaluation, explicit hypothesis conflicts, materialization integrity, population crossover, provider-backed planning, original artifacts across dev/baseline/calibration/admission/final, unknown usage preservation, native repair reserve exhaustion, and complete provider/materialization/evaluation outcome recovery. Five control tests cover independent session identities, frozen empty retrieval, protected capacity, pause/resume and zero-call recorded replay.

Planning and feedback absorption now have separate policy instances and checkpoint namespaces in schema 2. Feedback still enters memory, then reaches planning only through M5 projection. Custom policies relying on implicit shared absorb/ideate state must use explicit M5 transfer. Trusted Python globals and native execution are outside this interface guarantee.

The first full validation detected an A5 module dependency cycle. Pure recipes/role registration were separated from configured runtime orchestration; the existing architecture check then passed. Other observed RED→GREEN fixes include the schema-1 typed configuration boundary, retained feedback projection bypass, provider-backed ideation result shape, and bounded follow-up repairs. Historical tests were retained. The final frozen-source run passed 2,211 Linux tests, 76 tooling tests, 11 axioms, examples, builds and import integrity; source hashes were unchanged, exit 0 in 298.119 seconds.
