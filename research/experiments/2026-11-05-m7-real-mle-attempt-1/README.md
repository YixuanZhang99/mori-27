# First real M7 MLE pilot attempt

This is a failed, incomplete subset pilot, **not a benchmark score or an MLE-Bench Lite result**. It ran locally on 2026-11-05 Asia/Shanghai using source commit `ac9931a3c0105a949ca945a420f30a65d8853240`, the `deepseek-flash` API alias and a single local seed. The alias is mutable; an immutable model snapshot was not verified. The frozen plan called for three tasks and baseline/full arms (six runs), with official grading only after all submissions were frozen.

Both the local full check and local v74 acceptance passed. The corresponding GitHub Actions push had successful steps, including the complete job step, and its uploaded v74 artifact independently passed 55 checks against this exact source commit; the GitHub run still reported `in_progress` at dispatch and subsequently completed successfully. That timing distinction is recorded in the local launch receipt. The official grader and real task data were not copied into this report.

The first main run, `spooky-author-identification` baseline, failed before producing an admissible submission. One generated program reached isolated public-data execution but failed: its selected scikit-learn `liblinear` solver does not support the task's multiclass classification under the installed locked environment. Three subsequent main construction attempts were rejected because their output changed a frozen hypothesis. A resident control was also attempted. The pilot stopped without dispatching the remaining five task/arm slots and without official grading. The failed attempt is retained locally; no automatic retries occurred.

The existing shared CNY campaign had a settled upper bound of 3.242064 yuan before this attempt and 3.583228 yuan afterward, a 0.341164 yuan increase. The 200 yuan cumulative cap was not reset; no provider invocation remained unresolved or reserved. This is an accounting upper bound, not an independently reconciled invoice. No result, model superiority or statistical comparison can be inferred from the attempt.

Next work: make the frozen-hypothesis response rule explicit to the model while retaining the strict check; improve the MLE instructions and evidence-backed repair path for unsuccessful programs. Validate any changes before starting a separately recorded continuation under the same existing campaign budget. Preserve this attempt as a failed run rather than replacing it with the continuation.
